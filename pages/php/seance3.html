01

Le principe des conditions

Une condition permet d'exécuter un bloc de code uniquement si un test logique est vrai. C'est le cœur de la prise de décision côté serveur : « si la note est supérieure à 10, affiche la mention ».

En PHP, un test renvoie une valeur booléenne : true ou false. Ces deux valeurs sont des constantes : true vaut 1, false vaut 0.

🚦
Analogie : le feu de signalisation

Le test est le feu. S'il est vert (true), on avance : le code s'exécute. S'il est rouge (false), on s'arrête : le bloc est ignoré et PHP passe à la suite.

Les opérateurs de comparaison

OpérateurSignificationExempleRésultat
==Égalité (valeur)"10" == 10true
===Égalité stricte (valeur + type)"10" === 10false
!= / <>Différence5 != 6true
!==Différence stricte5 !== "5"true
< > <= >=Comparaison18 >= 18true
<=>Comparaison espace (3 valeurs)1 <=> 2-1
⚠️
Préférez toujours ===

Avec ==, PHP convertit les types avant de comparer : "0" == false vaut true, "abc" == 0 vaut aussi true (car "abc" vaut 0 en comparaison). Ces conversions ont provoqué des failles de sécurité. La comparaison stricte supprime l'ambiguïté.

02

if et else

Le bloc if s'exécute si le test est vrai, sinon c'est le bloc else qui s'exécute. Les accolades { } délimitent le bloc ; les point-virgules terminent les instructions.

PHP — if / else 
<?php
  $age = 20;

  if ($age >= 18) {
    echo "Vous êtes majeur.";
  } else {
    echo "Vous êtes mineur.";
  }
?>
RENDU

Vous êtes majeur.

📝
Sans accolades, un seul statement

Si vous oubliez les accolades, seule la première instruction du bloc est conditionnée :
if ($x) echo "a"; echo "b"; affiche b inconditionnellement. Écrivez toujours les accolades, même pour une ligne.

⚡ EXO FLASH Le piège sans accolades
  1. Créez accolades.php avec $connecte = false; puis, sans accolades : if ($connecte) echo "Bienvenue !"; echo "Au revoir.";. Prévoyez ce qui s'affiche, puis vérifiez.
  2. Passez $connecte = true; : les deux messages s'affichent — pourquoi le résultat est-il identique au cas précédent ?
  3. Ajoutez les accolades autour des deux echo et re-testez les deux valeurs : un seul message doit s'afficher à la fois.
Voir un début de correction 
<?php
  $connecte = false;

  // SANS accolades : seul le 1er echo est conditionné
  if ($connecte) echo "Bienvenue !"; echo "Au revoir.";   // affiche toujours "Au revoir."

  // AVEC accolades : les deux instructions appartiennent au bloc
  if ($connecte) {
    echo "Bienvenue !";
  } else {
    echo "Au revoir.";
  }
?>
03

elseif : plusieurs cas

elseif permet d'enchaîner plusieurs tests. Dès qu'un test renvoie true, les suivants ne sont pas évalués : on sort de la cascade. L'ordre des tests est donc important, du plus restrictif au plus général.

PHP — elseif 
<?php
  $note = 14;

  if ($note >= 16) {
    echo "Très bien";
  } elseif ($note >= 14) {
    echo "Bien";
  } elseif ($note >= 10) {
    echo "Moyen";
  } else {
    echo "Insuffisant";
  }
?>
RENDU

Bien

04

switch : comparer une valeur

Quand on compare la même variable à plusieurs valeurs possibles, switch est plus lisible qu'une cascade de elseif. Il utilise une comparaison stricte (===).

PHP — switch 
<?php
  $jour = "lundi";

  switch ($jour) {
    case "lundi":
      echo "Début de semaine";
      break;
    case "samedi":
    case "dimanche":
      echo "Week-end";
      break;
    default:
      echo "Jour ordinaire";
  }
?>
RENDU

Début de semaine

⚠️
L'oubli du break

Sans break, l'exécution « tombe » dans le cas suivant (fallthrough) et imprime plusieurs messages. C'est une source fréquente de bugs. Exception : le fallthrough volontaire, où l'on regroupe des cas (comme samedi et dimanche ci-dessus) en omettant volontairement le break sur le premier.

05

Opérateurs logiques

Les opérateurs logiques combinent plusieurs tests : && (et), || (ou), ! (non). Ils sont dit « à court-circuit » : si le premier test suffit à décider, le second n'est pas évalué.

PHP — && || ! 
<?php
  $age = 20;
  $permis = true;

  if ($age >= 18 && $permis) {
    echo "Vous pouvez conduire.";
  }

  if ($age < 18 || !$permis) {
    echo "Conduite interdite.";
  }
?>
RENDU

Vous pouvez conduire.

Valeurs « truthy » et « falsy »

PHP ne demande pas un booléen strict : toute valeur peut être évaluée comme vraie ou fausse.

TypeFalsy (faux)Truthy (vrai)
booléenfalsetrue
entier0tout le reste
float0.0tout le reste
chaîne"" et "0"tout le reste
tableau[] (vide)non vide
nullnull—
⚡ EXO FLASH Vrai ou faux ?
  1. Dans truthy.php, écrivez if ("0") { echo "vrai"; } else { echo "faux"; }. Prévoyez le résultat avant d'exécuter.
  2. Testez la même structure avec 0, "00", [0] et null : relevez les deux réponses surprenantes.
  3. Enchaînez avec un court-circuit : var_dump(false && $x); sans définir $x — pourquoi n'y a-t-il aucune erreur ?
Voir un début de correction 
<?php
  // Surprenants : "0" est falsy alors que "00" est truthy ; [0] est truthy bien que "vide"
  var_dump((bool)"0");    // false
  var_dump((bool)"00");   // true
  var_dump((bool)[0]);    // true — un tableau non vide est toujours vrai

  var_dump(false && $x);  // bool(false) — $x n'est jamais évaluée (court-circuit)
?>
06

Ternaire & null coalescing

L'opérateur ternaire condition ? valeur_si_vrai : valeur_si_faux condense un if/else en une expression. L'opérateur de coalescence ?? renvoie une valeur de repli si celle de gauche est null ou non définie.

PHP — Ternaire et ?? 
<?php
  $stock = 0;
  $message = $stock > 0 ? "En stock" : "Rupture";

  $pseudo = $_GET["pseudo"] ?? "Invité";

  echo $message;   // Rupture
  echo "<br>" . $pseudo;  // Invité
?>
RENDU

Rupture
Invité

💡
Ternaire ou if ?

Utilisez le ternaire pour un choix simple qui produit une valeur. Gardez le if dès qu'il y a plusieurs instructions, une structure complexe, ou que la lisibilité prime. Trop de ternaires imbriqués deviennent illisibles.

Deux variantes à connaître : le ternaire « court » $a ?: $b renvoie $a si elle est truthy, sinon $b (attention, 0 ?: 5 vaut bien 5), et l'affectation par coalescence $pseudo ??= "Invité"; n'affecte la valeur que si $pseudo est null ou non définie. Retenez la nuance : ?? teste « défini et non null », alors que ?: teste « truthy » — un "" ou un 0 passe avec ?? mais bascule sur le repli avec ?:.

07

Exercices pratiques

EX 01 🎂 Vérifier la majorité
  1. Créez exo_majeur.php avec une variable $age = 17;.
  2. Affichez « Vous êtes majeur » si $age >= 18, « Vous êtes mineur » sinon.
  3. Testez avec $age = 20 : le message doit changer.

Indice : un seul if suffit, pas besoin de elseif.

EX 02 📊 Mention à une note
  1. À partir d'une $note (0–20), affichez la mention : Très bien (≥16), Bien (≥14), Moyen (≥10), Insuffisant sinon.
  2. Utilisez une cascade if/elseif/else, du seuil le plus haut au plus bas.
  3. Affichez aussi la mention encadrée dans une balise <strong>.

Indice : l'ordre des tests détermine le résultat — commencez par 16.

EX 03 🔐 Accès autorisé
  1. Une zone est accessible si l'utilisateur est connecté ET son rôle est "admin".
  2. Affichez « Accès autorisé » ou « Accès refusé ».
  3. Ajoutez une troisième condition : si l'utilisateur est banni, l'accès est refusé même s'il est admin.

Indice : combinez && et ||, et placez le test du bannissement en premier.

EX 04 🗓️ Jour de la semaine
  1. Écrivez un switch sur une variable $jour (lundi → dimanche).
  2. Affichez « Week-end » pour samedi et dimanche (regroupez les deux cas), « Travail » en semaine.
  3. Ajoutez un default qui affiche « Jour inconnu ».

Indice : deux case qui partagent le même corps n'ont besoin d'un break qu'à la fin.

08

Bilan & mini-glossaire

Ce que vous maîtrisez

  • Le rôle d'une condition : exécuter un bloc selon un test vrai/faux
  • if / else / elseif et l'ordre d'évaluation
  • switch, case, break et default
  • Les opérateurs de comparaison, dont === et !==
  • Les opérateurs logiques &&, ||, ! et le court-circuit
  • Les valeurs truthy / falsy
  • L'opérateur ternaire et l'opérateur de coalescence ??
🚨
Erreurs fréquentes
  • Oublier le break dans un switch → plusieurs messages affichés.
  • Utiliser == au lieu de === → conversions de types inattendues.
  • Oublier les accolades → une seule instruction conditionnée.
  • Placer un test trop général avant un test restrictif → la cascade s'arrête trop tôt.
  • Écrire if ($x = 5) (affectation) au lieu de if ($x == 5) → toujours vrai.

Mini-glossaire

switch

Instruction qui sort du switch et évite le fallthrough.
