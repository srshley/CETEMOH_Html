01

Les types de données

PHP est un langage à typage dynamique : le type d'une variable est déterminé par la valeur qu'elle contient, pas par une déclaration. On parle de types scalaires (un seul contenu : nombre, texte, booléen) et de types compilés (tableau, objet, ressource).

PHP — gettype() sur chaque type 
<?php
  $entier  = 42;
  $decimal = 3.14;
  $texte   = "PHP";
  $booleen = true;
  $tableau = ["a", "b"];
  $vide    = null;

  echo gettype($entier),  "<br>";
  echo gettype($decimal), "<br>";
  echo gettype($texte),   "<br>";
  echo gettype($booleen), "<br>";
  echo gettype($tableau), "<br>";
  echo gettype($vide);
?>

PHP propose aussi des fonctions de test : is_int(), is_float(), is_string(), is_bool(), is_array(), is_null(). Elles renvoient un booléen et permettent d'écrire du code robuste face aux données reçues d'un formulaire ou d'une base.

02

Conversion de types (casting)

Le casting consiste à forcer une valeur vers un autre type en plaçant le type entre parenthèses devant l'expression : (int), (float), (string), (bool), (array). Il est indispensable quand une donnée arrive sous une forme inattendue — par exemple un prix reçu en chaîne depuis un formulaire.

PHP — Casting 
<?php
  $prix = "19.90";

  $entier = (int)$prix;      // 19
  $reel   = (float)$prix;    // 19.9
  $texte  = (string)42;      // "42"
  $vrai   = (bool)0;         // false
  $liste  = (array)"abc";    // tableau à 1 élément

  echo $entier, "<br>";
  echo $reel, "<br>";
  echo $texte, "<br>";
  echo ($vrai ? "true" : "false"), "<br>";
  echo count($liste), " element";
?>
RENDU

19.9
42
false
1 element

⚠️
Le piège du cast entier

(int)"19.90" vaut 19 et non 20 : le cast troncature, il n'arrondit pas. La conversion d'un float vers un int est donc perteuse : (int)19.99 donne 19. De même (int)"abc" vaut 0 et (int)null vaut 0. Pour un arrondi correct, utilisez round() sur un float : round((float)$prix, 2).

Enfin, attention à la conversion automatique : dans une expression, PHP convertit tout seul. "10" + 5 vaut 15 (la chaîne numérique est convertie en nombre), mais "abc" + 5 provoque une erreur fatale depuis PHP 8 : une chaîne non numérique ne peut plus participer à un calcul. Cette conversion masquait des erreurs de saisie sans rien dire : convertissez explicitement et vérifiez.

⚡ EXO FLASH Le cast qui tronque
  1. Créez casting.php avec $salaire = "2497.75";. Prévoyez les résultats de (int)$salaire et (float)$salaire avant de les afficher avec var_dump().
  2. Affichez le salaire arrondi à l'euro le plus proche avec round() : quel type round() renvoie-t-il ?
  3. Testez (int)"12 mois" et (int)"décembre" : pourquoi obtenez-vous 12 puis 0 ?
Voir un début de correction 
<?php
  $salaire = "2497.75";
  var_dump((int)$salaire);            // int(2497) — troncature, pas arrondi
  var_dump((float)$salaire);          // float(2497.75)
  var_dump(round((float)$salaire));   // float(2498) — round renvoie un float

  var_dump((int)"12 mois");           // int(12) — lit jusqu'au premier caractère non numérique
  var_dump((int)"décembre");          // int(0)   — aucun chiffre au début
?>
03

Opérateurs arithmétiques & d'affectation

Les opérateurs arithmétiques classiques sont +, -, *, /, % (modulo) et ** (puissance, disponible depuis PHP 5.6). Les opérateurs d'affectation combinent un calcul et une affectation en une seule instruction : +=, -=, *=, /=, %=, .=.

PHP — Arithmétique et affectation 
<?php
  $a = 17;
  $b = 5;

  echo $a + $b,  "<br>";   // 22
  echo $a - $b,  "<br>";   // 12
  echo $a * $b,  "<br>";   // 85
  echo $a / $b,  "<br>";   // 3.4
  echo $a % $b,  "<br>";   // 2
  echo $a ** 2, "<br>";   // 289

  $a += 3;   // 20
  $a -= 4;   // 16
  $a *= 2;   // 32
  $a /= 4;   // 8
  $a %= 3;   // 2

  echo $a;
?>

Deux subtilités : la division de deux entiers renvoie toujours un float (10 / 5 vaut 2 mais de type double), et le modulo d'un nombre négatif suit le signe du dividende (-7 % 3 vaut -1). Pour rester dans les entiers, utilisez intdiv(10, 3) qui vaut 3.

Le modulo % est l'opérateur le plus utile à repérer chez vous : il donne le reste d'une division entière. $nombre % 2 === 0 teste la parité, $secondes % 60 isole les secondes restantes, $i % 3 === 0 déclenche une action toutes les 3 itérations. Retenez aussi que $a += 3 n'est pas une « nouvelle valeur de $a » magique : c'est exactement équivalent à $a = $a + 3, évalué de droite à gauche.

04

Opérateurs de comparaison

Comparer, c'est poser une question au moteur : « sont-ils égaux ? ». PHP propose deux familles. L'égalité non stricte (==) compare les valeurs après conversion implicite ; l'égalité stricte (===) compare la valeur et le type. En développement, on utilise quasi toujours la version stricte.

PHP — == vs === 
<?php
  $entier = 10;
  $chaine = "10";

  var_dump($entier == $chaine);     // bool(true)
  var_dump($entier === $chaine);    // bool(false)
  var_dump($entier != $chaine);     // bool(false)
  var_dump($entier !== $chaine);    // bool(true)
  var_dump($entier <> $chaine);     // bool(false)
  var_dump($entier < $chaine);      // bool(false)
  var_dump($entier <=> $chaine);    // int(0)
?>

La comparaison <=> ( Spaceship ) est très pratique : elle renvoie -1 si la gauche est plus petite, 0 si elles sont égales et 1 sinon. Elle sert à trier des tableaux sans écrire trois conditions.

🪪
Analogie : la carte d'identité

La comparaison == regarde seulement le nom inscrit sur la carte : « 10 » et « 10 » sont « le même nom », même si l'un est un nombre et l'autre un texte. La comparaison === vérifie en plus la carte elle-même : même nom, même format. Deux personnes peuvent porter le même nom : seule la carte complète permet de les distinguer.

⚡ EXO FLASH Pièges de ==
  1. Créez comparaisons.php. Prévoyez le résultat (true ou false) de : 0 == "abc", "10" == "10.0", 10 == "10.0".
  2. Vérifiez avec var_dump() : la première vous surprend-elle ? Depuis PHP 8, une chaîne non numérique comparée à un entier est convertie en chaîne, plus l'inverse.
  3. Refaites les trois tests avec === : expliquez pourquoi les réponses deviennent systématiquement prévisibles.
Voir un début de correction 
<?php
  var_dump(0 == "abc");        // false — PHP 8 : "abc" n'est pas numérique, on compare "0" et "abc"
  var_dump("10" == "10.0");    // true  — deux chaînes numériques comparées comme nombres
  var_dump(10 == "10.0");      // true  — chaîne numérique convertie en nombre

  var_dump(0 === "abc");       // false — types différents : aucune conversion possible
  var_dump("10" === "10.0");   // false — comparaison caractère par caractère
  var_dump(10 === "10.0");     // false — int contre string
?>
05

Concaténation & interpolation

L'opérateur de concaténation est le point . (à ne pas confondre avec la concaténation de chaînes de Python ou la virgule de echo). Il assemble deux valeurs en une chaîne. L'interpolation est la forme la plus lisible : dans une chaîne entre guillemets doubles, PHP remplace automatiquement les variables par leur valeur.

PHP — Concaténation et interpolation 
<?php
  $prenom = "Alice";
  $score  = 17.5;

  $phrase = "Bonjour " . $prenom . " !";
  echo $phrase, "<br>";

  echo "Score de $prenom : $score points<br>";

  $litteral = 'Bonjour $prenom';
  echo $litteral;
?>
RENDU

Bonjour Alice !
Score de Alice : 17.5 points
Bonjour $prenom

📝
Guillemets doubles ou simples ?

Avec des guillemets doubles "…", les variables sont interpolées : "$nom" devient la valeur de $nom. Avec des apostrophes '…', tout est littéral : '$nom' reste le texte $nom. Pour afficher un dollar littéralement dans une chaîne double, échappez-le : "\$100". Dans les chaînes simples, \' échappe l'apostrophe.

Attention à la priorité des opérateurs : . est moins prioritaire que +, donc "Total : " . 1 + 2 vaut "Total : 3" et non "Total : 12". Quand vous voulez concaténer un calcul, mettez-le entre parenthèses : "Total : " . (1 + 2) — ce qui donne "Total : 3" — ou utilisez sprintf() pour un format maîtrisé.

06

Constantes & portée des variables

Une constante est une valeur immuable identifiée par un nom, sans le symbole $. Elle se déclare avec le mot-clé const ou la fonction define(). On les utilise pour les valeurs partagées : nom de l'application, version, TVA, clés d'API.

PHP — define() et const 
<?php
  define("APP_NOM", "MonSite");
  const TVA = 0.20;

  echo APP_NOM, "<br>";
  echo round(TVA * 100), "%<br>";
  echo APP_NOM . " — TVA " . TVA, "<br>";
  echo "Fichier : " . __FILE__, "<br>";
  echo "Ligne : " . __LINE__, "<br>";
  echo "Dossier : " . __DIR__;
?>

PHP fournit également des constantes magiques, calculées automatiquement par le moteur : elles donnent des informations sur le contexte d'exécution. __FILE__ donne le chemin complet du fichier, __LINE__ le numéro de la ligne courante et __DIR__ le dossier qui contient le fichier.

La portée décrit où une variable est visible. À l'intérieur d'une fonction, une variable créée dans le script principal n'existe pas : elle est dite locale. Pour y accéder, il faut la passer en paramètre (la bonne pratique) ou la déclarer global. Une variable déclarée static dans une fonction conserve sa valeur d'un appel à l'autre.

💡
define() ou const ?

const est un mot-clé : il est analysé à la compilation, doit être placé à la racine du fichier et ne peut pas être conditionné. define() est une fonction : elle s'exécute à l'exécution, peut donc être appelée dans une boucle ou une condition, et accepte une expression comme valeur. En pratique : const pour les constantes de configuration, define() pour les constantes calculées.

07

Exercices pratiques

EX 01🔁 Convertisseur de types
  1. Partez de $prix = "19.90"; (une chaîne).
  2. Convertissez-la en int, en float et en string avec le casting.
  3. Affichez les trois résultats et expliquez pourquoi l'entier vaut 19 et non 20.

Indice : le cast entier tronque la partie décimale ; utilisez round((float)$prix, 2) pour un arrondi.

EX 02🧮 Mini calculatrice
  1. Déclarez $x = 17; et $y = 5;.
  2. Affichez la somme, la différence, le produit, la division et le modulo.
  3. Réutilisez printf() pour afficher le quotient avec deux décimales.

Indice : printf("%.2f", $x / $y) affiche 3.40.

EX 03⚖️ == ou === ?
  1. Créez $nombre = 10; et $texte = "10";.
  2. Comparez-les avec == puis avec ===, et affichez les deux résultats avec var_dump().
  3. Ajoutez $vide = null; et testez $vide == false et $vide === false.

Indice : var_dump() distingue bool(true) de bool(false) et affiche le type entre parenthèses.

EX 04🏷️ Constantes de l'application
  1. Déclarez define("APP_NOM", "CETEMOH") et const APP_VERSION = "1.0.0";.
  2. Affichez un pied de page du type « MonSite — version 1.0.0 » en utilisant ces deux constantes.
  3. Ajoutez __FILE__ et __DIR__ pour afficher l'emplacement du fichier dans un commentaire HTML.

Indice : les constantes s'écrivent sans $, mais se lisent comme des variables.

08

Bilan & mini-glossaire

Ce que vous maîtrisez

  • Les types de données : int, float, string, bool, array, null
  • Le typage dynamique et les fonctions de test is_int(), is_string()…
  • Le casting : (int), (float), (string), (bool), (array)
  • Les opérateurs arithmétiques + - * / % ** et d'affectation += -= *= /= %= .=
  • La comparaison lâche == contre la comparaison stricte ===
  • La concaténation avec . et l'interpolation dans les guillemets doubles
  • Les constantes déclarées par const ou define(), et les constantes magiques
  • La portée des variables : globale, locale, global et static
🚨
Erreurs fréquentes
  • Utiliser == au lieu de === → conversions implicites et faux positifs.
  • Croire que (int)"19.90" vaut 20 → le cast tronque, il donne 19.
  • Écrire "Total : " . 1 + 2 en croyant concaténer 12 → la priorité de + l'emporte.
  • Oublier le point entre la variable et la chaîne → PHP cherche une constante nommée $nom… inexistante.
  • Mettre un $ devant une constante ($APP_NOM) ou déclarer const dans une fonction → erreur de syntaxe.
