01

Principe & déclaration

Une fonction est un bloc de code nommé et réutilisable. On l'écrit une fois, on l'appelle autant de fois que nécessaire, avec des données différentes. C'est le remède le plus simple à la duplication : au lieu de recopier dix fois le même calcul, on écrit une fonction et on l'appelle dix fois.

La déclaration suit toujours le même modèle : le mot-clé function, un nom en minuscules, des parenthèses qui accueillent les paramètres, puis un corps entre accolades. Une fonction déclarée ne fait rien tant qu'on ne l'appelle pas.

PHP — Première fonction 
<?php
  function saluer($nom) {
    echo "Bonjour $nom !<br>";
  }

  saluer("Alice");
  saluer("Bob");
  saluer("Chloe");
?>
RENDU

Bonjour Alice !
Bonjour Bob !
Bonjour Chloe !

☕
Analogie : la machine à café

Une fonction est une machine à café : on lui fournit des ingrédients (les entrées, c'est-à-dire les paramètres), elle effectue son traitement (le corps de la fonction), et elle rend un résultat (la sortie, le return). On ne reconstruit pas la machine à chaque tasse : on l'utilise, c'est tout.

02

Paramètres & arguments

Le paramètre est la variable écrite dans la déclaration ; l'argument est la valeur réellement passée lors de l'appel. L'ordre compte : le premier argument alimente le premier paramètre. Un paramètre peut avoir une valeur par défaut : s'il manque à l'appel, cette valeur est utilisée.

PHP — Paramètres et valeur par défaut 
<?php
  function total($prix, $quantite = 1, $tva = 0.20) {
    return $prix * $quantite * (1 + $tva);
  }

  echo total(10);           // 12
  echo "<br>" . total(10, 2);    // 24
  echo "<br>" . total(10, 2, 0); // 20
?>
RENDU

12
24
20

Les quatre types de paramètres

Type de paramètreSyntaxeComportement
Obligatoirefunction f($a)l'appel doit fournir une valeur, sinon erreur fatale (ArgumentCountError)
Avec valeur par défautfunction f($a = 0)valeur de repli si l'argument manque ; se place toujours après les obligatoires
Par référencefunction f(&$var)la fonction modifie la variable d'origine et non une copie
Variadiquefunction f(...$args)accepte un nombre illimité d'arguments, regroupés dans un tableau

Avec &$var, la modification effectuée dans la fonction persiste après l'appel ; avec ...$args, tous les arguments supplémentaires arrivent sous forme de tableau que l'on peut parcourir avec foreach.

⚡ EXO FLASH Une fonction, trois appels
  1. Dans poly.php, écrivez salutation($prenom = "invité", $politesse = "Bonjour") qui return « $politesse, $prenom ! ». Appelez-la sans argument, avec un seul, puis avec deux.
  2. Écrivez moyenne(...$notes) qui additionne les arguments reçus avec array_sum() et divise par count(). Que renvoie moyenne(12, 15, 9) ?
  3. Déclarez function f($a = 0, $b) puis appelez-la avec un seul argument : lisez l'erreur ArgumentCountError. Pourquoi les valeurs par défaut doivent-elles toujours être déclarées en dernier ?
Voir un début de correction 
<?php
  function salutation($prenom = "invité", $politesse = "Bonjour") {
    return "$politesse, $prenom !";
  }
  echo salutation();                 // Bonjour, invité !
  echo salutation("Alice");          // Bonjour, Alice !
  echo salutation("Ali", "Salut");   // Salut, Ali !

  function moyenne(...$notes) {
    return array_sum($notes) / count($notes);
  }
  echo moyenne(12, 15, 9);           // 12 — les 3 arguments arrivent en tableau
?>
03

Valeur de retour

return renvoie une valeur à l'appelant. La fonction produit un résultat au lieu de l'afficher : c'est l'appelant qui décide quoi en faire, le stocker dans une variable, le combiner à un calcul ou l'afficher avec echo. On préfère donc return à echo dans la plupart des fonctions.

PHP — return 
<?php
  function aireRectangle($largeur, $hauteur) {
    return $largeur * $hauteur;
  }

  $surface = aireRectangle(5, 4);
  echo "Surface : $surface m2";
?>
RENDU

Surface : 20 m2

Un return peut renvoyer n'importe quelle valeur : entier, chaîne, tableau… ou aucune valeur utile. Une fonction qui renvoie un booléen, comme estValide($note), se combine très bien avec les conditions de la séance 3.

📝
Trois règles à retenir

1. Une fonction s'arrête dès qu'elle rencontre un return : les instructions placées après ne sont jamais exécutées.
2. Une fonction sans return renvoie null sans le dire : si votre variable vaut null, cherchez d'abord un return oublié.
3. return n'est pas echo : renvoyer met une valeur à disposition, afficher l'imprime à l'écran.

PHP permet d'annoncer le type de retour après la liste des paramètres : function aire(float $l, float $h): float. Si la fonction ne renvoie rien, écrivez : void. Le moteur vérifie alors à l'exécution : une TypeError trahit immédiatement une valeur mal renvoyée, au lieu d'un bug silencieux plus loin dans le script. C'est aussi une documentation vivante : en lisant la signature, on sait ce que la fonction attend et ce qu'elle produit.

04

Portée des variables

Chaque fonction a son propre « univers » : une variable créée à l'intérieur est locale et disparaît à la fin de l'appel. Deux variables qui portent le même nom — une globale et une locale — sont deux variables distinctes. Pour atteindre une variable globale depuis une fonction, on déclare global $x; au début du corps. Avec static $x = 0;, la variable est locale mais conservée entre les appels.

PHP — global et static 
<?php
  $tva = 0.20;

  function prixTTC($prixHT) {
    global $tva;
    return $prixHT * (1 + $tva);
  }

  function compteurVisites() {
    static $visites = 0;
    $visites++;
    return $visites;
  }

  echo prixTTC(100);               // 120
  echo "<br>" . compteurVisites(); // 1
  echo "<br>" . compteurVisites(); // 2
?>
RENDU

120
1
2

PortéeMot-cléVisible où ?
Locale(aucun)uniquement dans la fonction où elle est créée
Globaleglobal $x;dans la fonction, après l'import ; partout ailleurs par défaut
Statiquestatic $x = 0;dans la fonction, avec mémoire entre les appels
Super-globales$_GET, $_POST, $_SESSIONpartout, y compris à l'intérieur des fonctions
💡
Préférez les paramètres à global

Une fonction qui dépend de variables cachées (globales) devient imprévisible : on ne voit pas ce qu'elle utilise. Passez les valeurs en paramètres et renvoyez le résultat avec return : la fonction est alors autonome, prévisible et réutilisable. Gardez static pour les compteurs et les mémoires ponctuelles.

05

Fonctions natives utiles

PHP embarque des milliers de fonctions prêtes à l'emploi, par genre : tableaux, chaînes de caractères, nombres, dates. Pas besoin de réinventer la roue : avant d'écrire une fonction, cherchez si elle existe déjà. En voici huit que vous utiliserez dès la semaine prochaine.

FonctionCatégorieExemple d'appel
count($tab)tableaucount([10, 20, 30]) → 3
strlen($texte)chaînestrlen("Bonjour") → 7
strtoupper($texte)chaînestrtoupper("ok") → "OK"
number_format($n, 2)nombrenumber_format(1234.5, 2) → "1,234.50"
date($format)datedate("d/m/Y") → "22/10/2026"
in_array($val, $tab)tableauin_array(20, [10, 20]) → true
implode($sep, $tab)tableauimplode(", ", ["a", "b"]) → "a, b"
array_sum($tab)tableauarray_sum([10, 20]) → 30
PHP — Appel de fonctions natives 
<?php
  $panier = ["Stylo", "Gomme", "Regle"];

  echo "Articles : " . count($panier) . "<br>";
  echo "Liste : " . implode(", ", $panier) . "<br>";
  echo "En majuscules : " . strtoupper($panier[0]);
?>
RENDU

Articles : 3
Liste : Stylo, Gomme, Regle
En majuscules : STYLO

La documentation officielle (php.net) documente chaque fonction : nom, paramètres, valeur de retour, exemples. Le réflexe « je vais vérifier sur php.net » vous fera gagner des heures.

06

Closures & fonctions fléchées

Une fonction n'a pas besoin d'un nom : une fonction anonyme (closure) peut être stockée dans une variable, passée à une autre fonction, ou créée à la volée. Comme elle ne connaît pas les variables extérieures, elle doit les capter explicitement avec use ($var). Les fonctions fléchées (PHP 7.4+) font la même chose en une ligne et captent automatiquement une variable du contexte.

PHP — Closure et fonction fléchée 
<?php
  $notes = [8, 12, 16];
  $marge = 2;

  // function anonyme : capte $marge avec use
  $bonifier = function ($note) use ($marge) {
    return $note + $marge;
  };

  // fonction flechee : capte automatiquement $marge
  $double = fn($n) => $n * 2;

  echo implode(", ", array_map($bonifier, $notes));
  echo "<br>" . implode(", ", array_map($double, $notes));
?>
RENDU

10, 14, 18
16, 24, 32

Les closures servent surtout de callbacks : on les passe à array_map (transformer chaque élément), array_filter (garder certains éléments), usort (trier avec une règle personnalisée). La fonction qui reçoit le callback se charge de l'appeler pour chaque élément.

📝
La différence essentielle

La closure capte une variable par use et reçoit une copie de sa valeur au moment de la création. La fonction fléchée fn($n) => $n * 2 capte tout le contexte automatiquement, par valeur elle aussi, et ne peut contenir qu'une seule expression — pas de bloc { } ni d'instructions multiples.

⚡ EXO FLASH Filtrer et transformer un panier
  1. Dans closures.php, partez de $prix = [12.5, 3.9, 45.0, 8.0];. Utilisez array_filter() avec une fonction fléchée pour ne garder que les prix supérieurs à 10.
  2. Appliquez ensuite array_map(fn($p) => $p * 1.2, …) aux prix filtrés : vous obtenez le prix TTC (+20 %). Combien d'éléments affiche le résultat ?
  3. Même transformation avec une closure classique function ($p) use ($taux) où $taux = 1.2;. Puis retirez le use : lisez l'erreur et expliquez ce qu'elle dit.
Voir un début de correction 
<?php
  $prix  = [12.5, 3.9, 45.0, 8.0];
  $taux  = 1.2;

  $cherts = array_filter($prix, fn($p) => $p > 10);      // 12.5 et 45.0 → 2 éléments
  $ttc    = array_map(fn($p) => $p * 1.2, $cherts);      // 15 et 54

  $ttc2   = array_map(function ($p) use ($taux) {        // équivalent closure
    return $p * $taux;
  }, $cherts);
  // Sans use($taux) : Warning: Undefined variable $taux — la closure
  // ne voit pas le monde extérieur par défaut.
?>
07

Exercices pratiques

EX 01 ➕ Calculer un périmètre
  1. Créez exo_perimetre.php avec une fonction perimetre($longueur, $largeur).
  2. La fonction renvoie le périmètre du rectangle : deux fois la somme de ses côtés.
  3. Affichez le résultat de perimetre(5, 3) : il doit valoir 16. Testez aussi perimetre(2.5, 4).

Indice : return ($longueur + $largeur) * 2; — pensez à return, pas à echo.

EX 02 🎓 Mention en fonction
  1. Écrivez mention($note) qui renvoie une chaîne : "Très bien" (≥16), "Bien" (≥14), "Passable" (≥10), "Insuffisant" sinon.
  2. Affichez le résultat de mention(15) et de mention(8).
  3. Transformez le paramètre en $note = 10 et vérifiez que mention() fonctionne sans argument.

Indice : la fonction combine if / elseif / else et return — un return par branche.

EX 03 🔁 Compteur de visites
  1. Créez visites() avec une variable static $n = 0; incrémentée puis renvoyée.
  2. Appelez la fonction trois fois et affichez chaque valeur : 1, 2, 3.
  3. Retirez le mot-clé static et observez le compteur repartir à 1 à chaque appel.

Indice : static n'initialise la variable qu'au premier appel ; PHP la conserve ensuite entre les appels.

EX 04 📦 Moyenne variadique
  1. Écrivez moyenne(...$notes) qui renvoie la moyenne de tous les arguments passés.
  2. Testez avec moyenne(10, 12, 14) : le résultat doit valoir 12.
  3. Affichez la moyenne formatée avec number_format($moyenne, 2).

Indice : avec ...$notes, les arguments arrivent sous forme de tableau — utilisez array_sum() et count().

Bilan & mini-glossaire

Ce que vous maîtrisez

  • Déclarer une fonction avec function et l'appeler par son nom
  • La différence entre paramètre (déclaration) et argument (appel)
  • Les paramètres obligatoires, avec valeur par défaut, par référence et variadiques
  • Renvoyer une valeur avec return, et le null produits sans return
  • La portée locale / globale / statique des variables
  • Les super-globales accessibles partout, y compris dans les fonctions
  • Les fonctions natives les plus courantes : count, strlen, implode, date…
  • Les closures avec use et les fonctions fléchées fn() => en callback
🚨
Erreurs fréquentes
  • Oublier le return puis s'étonner que le résultat vaille null.
  • Placer un paramètre avec valeur par défaut avant un paramètre obligatoire → erreur fatale.
  • Utiliser global partout au lieu de passer des paramètres.
  • Écrire du code après un return : il n'est jamais exécuté (code mort).
  • Redéclarer une fonction au nom déjà pris → « Cannot redeclare » (une fonction est unique).

Mini-glossaire

Fonction
Bloc de code nommé, exécutable à volonté avec des données différentes.
Paramètre
Variable déclarée dans la signature de la fonction.
Argument
Valeur réellement passée lors de l'appel de la fonction.
return
Termine la fonction et renvoie une valeur à l'appelant.
Portée
Zone du code où une variable est visible.
static
Variable locale conservée entre les appels de la fonction.
Closure
Fonction anonyme, stockable dans une variable, capte son contexte avec use.
Fonction fléchée
Syntaxe courte fn($n) => expression qui capte le contexte automatiquement.
Callback
Fonction passée en argument à une autre fonction (array_map, usort…).
