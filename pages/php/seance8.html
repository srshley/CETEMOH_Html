01

Fonctions de base

Toute chaîne a une longueur, une casse, et souvent des espaces parasites en début ou fin. Cinq fonctions couvrent ces opérations élémentaires : elles ne modifient jamais la chaîne d'origine, elles renvoient une nouvelle chaîne à stocker dans une variable.

PHP — Mesurer, changer la casse, nettoyer 
<?php
  $saisie = "  sarA Ben ali  ";

  $propre = trim(strtolower($saisie));
  echo "Longueur : " . strlen($propre) . "<br>";
  echo "Nom : " . ucfirst($propre) . "<br>";
  echo "Code produit : " . strtoupper($propre);
?>
RENDU

Longueur : 12
Nom : Sara ben ali
Code produit : SARA BEN ALI

FonctionRôleExemple
strlen($s)renvoie la longueur de la chaînestrlen("PHP") → 3
strtoupper($s)tout en majusculesstrtoupper("ok") → "OK"
strtolower($s)tout en minusculesstrtolower("OK") → "ok"
ucfirst($s)première lettre en majusculeucfirst("ali") → "Ali"
trim($s)supprime espaces (aux deux bouts)trim(" a ") → "a"
📝
Les chaînes sont immuables

strtolower($s) ne change pas $s : il renvoie une copie. Pour garder le résultat, affectez-le : $s = strtolower($s);. Cette règle vaut pour presque toutes les fonctions de chaînes — contrairement aux fonctions de tri de tableaux (sort), qui agissent par référence.

⚡ EXO FLASH Nettoyer une saisie
  1. Déclarez dans exo_chaine.php la saisie mal rangée $saisie = " le php ";.
  2. Prévoyez ce qu'affiche strlen($saisie) — espaces compris ! — puis vérifiez.
  3. Nettoyez avec trim() puis ucfirst(), et affichez la chaîne propre et sa nouvelle longueur.
Voir un début de correction 
<?php
  $saisie = "  le php  ";
  echo strlen($saisie) . "<br>";
  $propre = ucfirst(trim($saisie));
  echo $propre . " (" . strlen($propre) . ")";
?>
02

Chercher & remplacer

Pour tester la présence d'un mot : strpos renvoie la position de la première occurrence (0 = premier caractère, false si absent) et str_contains renvoie directement un booléen. Pour substituer : str_replace remplace toutes les occurrences, et substr_replace remplace une portion selon sa position et sa longueur.

PHP — strpos, str_contains, str_replace 
<?php
  $phrase = "Le chat dort sur le tapis";

  if (str_contains($phrase, "chat")) {
    echo "Le mot chat figure dans la phrase<br>";
  }
  $pos = strpos($phrase, "dort");
  echo "Position de 'dort' : $pos<br>";

  echo str_replace("chat", "chien", $phrase) . "<br>";

  echo substr_replace($phrase, "MAT", 3, 4);
?>
RENDU

Le mot chat figure dans la phrase
Position de 'dort' : 8
Le chien dort sur le tapis
Le MAT dort sur le tapis

⚠️
Le piège du 0 dans strpos

strpos("PHP", "P") renvoie 0… qui est falsy ! Tester if (strpos($s, $x)) rate les occurrences au premier caractère. Utilisez toujours if (strpos($s, $x) !== false), ou mieux : str_contains() (PHP 8), qui renvoie un vrai booléen.

📝
str_replace accepte des tableaux

str_replace(["a", "e", "i"], "", $texte) remplace les trois lettres d'un coup ; str_replace(["old1", "old2"], ["new1", "new2"], $texte) aligne chaque recherche sur son remplacement. La casse est respectée : pour ignorer la casse, utilisez str_ireplace.

03

Découper & joindre

explode($separateur, $chaine) découpe une chaîne en tableau ; implode($collant, $tableau) fait l'inverse. C'est le pont entre les chaînes et les tableaux de la séance 7 : une ligne CSV, une URL segmentée, une liste de tags — tout se manipule en tableau une fois explosé.

PHP — explode, implode, str_split 
<?php
  $csv = "Ali;Maths;15";

  $champs = explode(";", $csv);
  echo $champs[0] . " a eu " . $champs[2] . "<br>";
  echo implode(" | ", $champs) . "<br>";

  $code = "A7XC";
  print_r(str_split($code));
?>
RENDU

Ali a eu 15
Ali | Maths | 15
Array ( [0] => A [1] => 7 [2] => X [3] => C )

🧩
Analogie : le colis et le frigo

explode reçoit un colis livré d'un seul tenant et le décompose sur une étagère : chaque morceau devient une case du tableau, facile à atteindre individuellement. implode fait l'inverse : il reconstitue le tout en une seule pièce, avec le séparateur de votre choix. Même colis, simplement rangé différemment.

04

Extraire & formater

substr($s, $debut, $longueur) extrait une sous-chaîne : $debut peut être négatif pour compter depuis la fin. Pour l'affichage, number_format règle décimales et séparateurs, et sprintf injecte des valeurs dans un gabarit (%s chaîne, %d entier, %.2f flottant à 2 décimales).

PHP — substr, number_format, sprintf 
<?php
  $ref = "CMD-2026-0142";
  echo "Sous-chaîne : " . substr($ref, 4, 4) . "<br>";   // 2026
  echo "Fin : " . substr($ref, -4) . "<br>";             // 0142
  $montant = 1234567.891;
  echo number_format($montant, 2, ",", " ") . "<br>";
  echo sprintf("%s a %d ans, moyenne %.2f", "Sara", 19, 14.567);
?>
RENDU

Sous-chaîne : 2026
Fin : 0142
1 234 567,89
Sara a 19 ans, moyenne 14.57

💡
sprintf plutôt que la concaténation

Dès que vous assemblez plus de deux valeurs, sprintf gagne en lisibilité et en sûreté : le gabarit montre la phrase finale d'un seul regard, et chaque spécificateur (%d, %.2f) force un format précis — %d sur une valeur non numérique donnera 0 au lieu d'une erreur d'affichage.

05

Les expressions régulières

Une expression régulière (regex) décrit un motif : « quatre chiffres, un tiret, deux lettres ». En PHP (fonctions preg_*, moteur PCRE), le motif s'écrit entre délimiteurs, le plus souvent des slashes : /motif/. preg_match teste la première correspondance, preg_match_all les trouve toutes, preg_replace les remplace.

PHP — preg_match et preg_replace 
<?php
  $tel = "06-12-34-56-78";

  // deux chiffres, tiret, deux chiffres
  if (preg_match("/^\d{2}-\d{2}/", $tel)) {
    echo "Format de debut correct<br>";
  }
  preg_match_all("/\d{2}/", $tel, $trouves);
  echo "Paires trouvees : " . count($trouves[0]) . "<br>";

  echo preg_replace("/\d/", "*", $tel);
?>
RENDU

Format de debut correct
Paires trouvees : 5

Les métacaractères essentiels

Quand un caractère ordinaire (lettre, chiffre) se lit tel quel, un métacaractère code une idée : « n'importe quelle lettre », « répété un ou plusieurs fois », « début de ligne »… Pour chercher un métacaractère littéral, on le précède d'un antislash : \. cherche un vrai point.

MotifSignificationExemple
.n'importe quel caractère (sauf retour à la ligne)/.at/ trouve bat, cat, 1at
*l'élément précédent, répété 0 fois ou plus/ab*c/ trouve ac, abc, abbc
+l'élément précédent, répété 1 fois ou plus/ab+c/ trouve abc, abbc mais pas ac
?l'élément précédent, 0 ou 1 fois (optionnel)/colou?r/ trouve color et colour
[abc]un caractère de l'ensemble (ou plage [0-9a-z])/[A-Z]{3}/ trouve CMD
^ $début / fin de la chaîne/^\d\d$/ : exactement deux chiffres
\dun chiffre (équivalent [0-9])/\d{4}/ : quatre chiffres consécutifs
\wun caractère de mot (lettre, chiffre, _)/\w+/ : un mot entier
\sun espace blanc (espace, tabulation…)/\s+/ : un ou plusieurs espaces
⚠️
Protégez le motif en PHP

Un motif entre guillemets doubles traite \d comme une séquence d'échappement de PHP (« d »), ce qui peut déformer le motif. Écrivez vos regex en chaînes à guillemets simples : '/\d{4}/' — ainsi l'antislash est transmis intact au moteur PCRE.

⚡ EXO FLASH Un motif simple
  1. Dans exo_regex.php, écrivez un motif qui accepte exactement trois lettres majuscules (début et fin ancrés).
  2. Prévoyez si "CMD" et "cmd9" passent ce test, puis vérifiez avec preg_match().
  3. Comptez avec preg_match_all('/\d/', $texte, $m) le nombre de chiffres contenus dans "A1 B22".
Voir un début de correction 
<?php
  $code = "CMD";
  echo preg_match('/^[A-Z]{3}$/', $code) ? "OK" : "KO";
  preg_match_all('/\d/', "A1 B22", $m);
  echo "<br>" . count($m[0]) . " chiffres";
?>
06

Validation avec filter_var

Écrire à la main une regex qui valide tous les e-mails valides est quasi impossible. PHP fournit filter_var($valeur, FILTRE) : une validation prête à l'emploi pour l'e-mail, l'URL, l'entier… Elle renvoie la valeur validée ou false. On l'utilisera encore davantage à la séance suivante, avec les formulaires.

PHP — FILTER_VALIDATE_EMAIL / URL 
<?php
  $email = "sara.benali@cecemoh.ma";

  if (filter_var($email, FILTER_VALIDATE_EMAIL)) {
    echo "E-mail valide<br>";
  }
  $url = "https://cecemoh.ma/cours/php";
  echo filter_var($url, FILTER_VALIDATE_URL)
       ? "URL valide"
       : "URL invalide";
?>
RENDU

E-mail valide
URL valide

💡
Regex ou filter_var ?

Règle simple : si un filtre standard existe (e-mail, URL, entier, flottant, IP), utilisez filter_var — le motif est maintenu par PHP lui-même. Gardez les regex pour les formats métier sans filtre natif : code postal, numéro de commande, matricule interne…

Gare à la valeur de retour : filter_var() renvoie la donnée validée et non un simple booléen. Un entier légitime comme 0 est bien accepté par FILTER_VALIDATE_INT, mais le résultat 0 est falsy : testez l'échec avec === false, sinon un « 0 » parfaitement valide sera confondu avec un refus. Il existe aussi la variante FILTER_SANITIZE_* qui, au lieu de valider, nettoie la chaîne — FILTER_SANITIZE_EMAIL retire par exemple les caractères interdits dans un e-mail.

Exercices pratiques

EX 01 🧼 Nettoie et met en forme
  1. Créez exo_nom.php avec une saisie aux abords sales : " jeAn dUPont ".
  2. Affichez le nom nettoyé, avec majuscule initiale : Jean dupont.
  3. Affichez ensuite sa version majuscule complète et sa longueur.

Indice : enchaînez trim → strtolower → ucfirst ; chaque fonction renvoie une copie, donc affectez le résultat.

EX 02 🏷️ Liste de tags
  1. Partez d'une chaîne $tags = "php, mysql, html, css".
  2. Explosez-la en tableau, puis affichez chaque tag numéroté : 1. php…
  3. Rejoignez les tags avec implode(" + ", ...) sans les espaces après virgule.

Indice : trim chaque élément du tableau résultat avec array_map('trim', $t) avant de joindre.

EX 03 📮 Regex de code postal
  1. Écrivez un motif qui valide exactement 5 chiffres consécutifs : début et fin de chaîne imposés.
  2. Testez "75011" (valide), "7501a" (invalide) et "123456" (invalide).
  3. Affichez « Valide » ou « Invalide » pour chacun des trois tests.

Indice : '/^\d{5}$/' — ancrez début ^ et fin $, sinon "123456" passera.

EX 04 ✉️ Validation de coordonnées
  1. Créez un tableau $donnee avec un e-mail, une URL et un âge.
  2. Validez chacun les filtres FILTER_VALIDATE_EMAIL, FILTER_VALIDATE_URL et FILTER_VALIDATE_INT.
  3. Affichez une ligne par champ : « E-mail : valide / invalide ».

Indice : bouclez foreach sur le tableau et testez filter_var($v, $filtre) === false pour repérer un échec.

08

Bilan & mini-glossaire

Ce que vous maîtrisez

  • Mesurer et recadrer une chaîne : strlen, trim, casse
  • Chercher sans piège : strpos avec !== false, str_contains
  • Remplacer : str_replace (même en tableau) et substr_replace
  • Le pont chaîne ↔ tableau : explode / implode / str_split
  • Extraire et formater : substr, number_format, sprintf
  • Un motif regex : métacaractères . * + ? [] ^ $ \d \w \s
  • Les fonctions PCRE : preg_match, preg_match_all, preg_replace
  • La validation standard avec filter_var et ses filtres
🚨
Erreurs fréquentes
  • Tester if (strpos(...)) → la position 0 est traitée comme un échec.
  • Oublier les ancres ^ et $ → le motif valide une chaîne qui n'a que le bon format.
  • Écrire une regex entre guillemets doubles → \d est avalé par PHP avant PCRE.
  • Chercher un point avec /./ → ça matche tout ; écrivez un vrai point /\./.
  • Confondre * et + → * accepte l'absence, + exige au moins une occurrence.

Mini-glossaire

Longueur
Nombre de caractères d'une chaîne, via strlen.
Casse
Distinction minuscules / majuscules ; modifiée par strto* et ucfirst.
Position
Indice du premier caractère d'une occurrence, renvoyé par strpos (0-based).
Explode / Implode
Découpe une chaîne en tableau / rejoint un tableau en chaîne.
Substring
Extrait de chaîne renvoyé par substr à partir d'une position et d'une longueur.
Motif (pattern)
Description formelle d'un format de texte, encadré par des délimiteurs /…/.
Métacaractère
Caractère spécial d'une regex (., +, \d…) codant une classe ou une répétition.
Filtre
Validation prête à l'emploi appliquée par filter_var (e-mail, URL, entier…).
