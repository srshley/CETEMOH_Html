01

Le principe des boucles

Une boucle permet d'exécuter le même bloc de code plusieurs fois, sans le recopier. On décrit une seule fois l'opération à répéter, et on laisse PHP la répéter tant qu'une condition de continuation reste vraie. C'est le principe de la répétition contrôlée : la répétition n'est jamais sauvage, elle est pilotée par un test et, le plus souvent, par un compteur qui avance à chaque tour.

Chaque passage dans la boucle s'appelle une itération. La boucle s'arrête dès que la condition de continuation devient fausse. PHP propose trois familles de boucles : for quand on connaît le nombre de tours, while / do...while quand on ne le connaît pas à l'avance, et foreach pour parcourir les éléments d'un tableau.

🏃
Analogie : le coureur sur une piste

Le coureur fait des tours de piste. Le test, c'est le coup de sifflet : tant qu'il n'a pas sonné, le coureur continue. Chaque tour de piste est une itération. Si le coureur oublie d'avancer sur la piste, il tourne indéfiniment : c'est la boucle infinie.

À chaque tour, le même schéma se répète : PHP évalue le test ; s'il est vrai, il exécute le corps de la boucle, puis fait avancer le compteur, puis revient au test. La boucle est donc une condition qui se répète : tout ce que vous avez appris sur les conditions de la séance 3 s'applique ici.

02

La boucle for

La boucle for concentre les trois étapes du schéma sur une seule ligne : for ($i = 0; $i < N; $i++) { … }. C'est la boucle à utiliser dès qu'on sait combien de fois le bloc doit s'exécuter : afficher une table de multiplication, générer une série de nombres, numéroter des lignes.

PHP — Table de multiplication de 2 
<?php
  for ($i = 1; $i <= 10; $i++) {
    echo "2 x $i = " . (2 * $i) . "<br>";
  }
?>
RENDU

2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
2 x 4 = 8
2 x 5 = 10
2 x 6 = 12
2 x 7 = 14
2 x 8 = 16
2 x 9 = 18
2 x 10 = 20

📝
Les trois parties du for

1. Initialisation — exécutée une seule fois avant le premier tour : $i = 1.
2. Test — évalué avant chaque tour : tant qu'il vaut true, on continue ($i <= 10).
3. Incrément — exécuté après chaque tour : c'est lui qui fait avancer le compteur ($i++).

L'ordre des tours est toujours test → corps → incrément : le compteur est vérifié avant d'être incrémenté. La variable de compteur est une variable ordinaire : vous pouvez la nommer $i, $index ou $numero_ligne, et l'utiliser dans le corps du bloc.

⚡ EXO FLASH Compter à l'envers
  1. Dans decompte.php, écrivez une boucle for qui affiche 10 9 8 … 1 Décollage ! en partant de $i = 10 et en descendant de 1 à chaque tour.
  2. Prévoyez combien de tours exécute for ($i = 0; $i < 0; $i++) avant de la tester avec un echo dans le corps.
  3. Transformez votre décompte en while équivalent : même sortie, trois lignes de moins ?
Voir un début de correction 
<?php
  for ($i = 10; $i >= 1; $i--) {
    echo $i . " ";
  }
  echo "Décollage !<br>";

  // 0 tour : le test est faux dès le départ, le corps n'entre jamais
  for ($i = 0; $i < 0; $i++) { echo "jamais affiché"; }

  $i = 10;
  while ($i >= 1) { echo $i . " "; $i--; }   // équivalent while
?>
03

while et do...while

Quand le nombre de tours n'est pas connu à l'avance, on utilise while. Sa syntaxe est simple : while (condition) { … }. Le bloc est exécuté tant que la condition est vraie, et la condition est testée avant chaque tour. À vous de faire évoluer une variable dans le corps pour que la condition finisse par être fausse.

PHP — while 
<?php
  $solde   = 120;
  $retrait = 40;
  $mois    = 0;

  while ($solde > 0) {
    $solde -= $retrait;
    $mois++;
    echo "Mois $mois : solde $solde EUR<br>";
  }
?>
RENDU

Mois 1 : solde 80 EUR
Mois 2 : solde 40 EUR
Mois 3 : solde 0 EUR

Le do...while ressemble à while, mais le test est placé à la fin du bloc : do { … } while (condition);. Le bloc s'exécute donc au moins une fois, même si la condition est déjà fausse. C'est la boucle idéale pour un menu, une saisie utilisateur ou toute action qu'on veut tenter au moins une fois.

PHP — do...while 
<?php
  $essais = 0;

  do {
    echo "Tentative " . ($essais + 1) . "<br>";
    $essais++;
  } while ($essais < 3);

  // condition deja fausse au depart :
  // le bloc est execute une fois quand meme
  $code = 999;
  do {
    echo "Ce message s'affiche une seule fois";
  } while ($code < 10);
?>
RENDU

Tentative 1
Tentative 2
Tentative 3
Ce message s'affiche une seule fois

Le moment du test change tout

BoucleMoment du testMinimum d'exécutions
foravant chaque tour0 (si le test est faux dès le départ)
whileavant chaque tour0 (si la condition est fausse dès le départ)
do...whileaprès chaque tour1, quoi qu'il arrive
foreachsur le nombre d'éléments0 (si le tableau est vide)
04

foreach : parcourir un tableau

foreach est la boucle dédiée aux tableaux. Au lieu de gérer un indice, elle récupère automatiquement chaque élément : foreach ($tableau as $valeur). Sur un tableau associatif, on peut aussi récupérer la clé en même temps que la valeur : foreach ($tableau as $cle => $valeur).

PHP — foreach sur un panier 
<?php
  $panier = [
    "pain" => 2.50,
    "lait" => 1.20,
    "cafe" => 4.90
  ];

  foreach ($panier as $produit => $prix) {
    echo $produit . " : " . $prix . " EUR<br>";
  }
?>
RENDU

pain : 2.5 EUR
lait : 1.2 EUR
cafe : 4.9 EUR

Sur un tableau indexé, la clé est simplement l'indice : foreach ($fruits as $index => $fruit) donne $index = 0, 1, 2… Si on n'a pas besoin de la clé, on écrit foreach ($fruits as $fruit) : c'est plus court et plus lisible.

💡
Préférez foreach à for sur les tableaux

Un foreach ne peut pas se « dépasser » : il s'arrête exactement à la fin du tableau, quel que soit son nombre d'éléments. Un for mal écrit (mauvaise borne) provoque un décalage ou une erreur « undefined offset ». Réservez le for aux séquences numériques : for ($i = 1; $i <= 10; $i++).

Point crucial : sans le savoir, on écrase souvent des données. Par défaut, foreach ($t as $v) travaille sur une copie de chaque élément — modifier $v ne change pas le tableau. Pour modifier en place, ajoutez l'esperluette : foreach ($t as &$v), puis unset($v); juste après la boucle (sinon la variable « fantôme » continue de pointer le dernier élément et le modifie par accident). Autre piège : modifier la structure du tableau (ajouter/supprimer des clés) pendant un foreach donne des résultats imprévisibles — utilisez alors une boucle for parcourue à l'envers.

05

break et continue

Deux instructions permettent de contrôler le déroulement d'une boucle. break arrête la boucle et passe à la suite du script. continue saute le reste du corps de la boucle et passe directement à l'itération suivante. Dans une boucle for, l'incrément est malgré tout exécuté après un continue ; dans un while, attention : tout ce qui suit le continue est ignoré, y compris l'incrément manuel.

PHP — break et continue 
<?php
  for ($i = 1; $i <= 10; $i++) {
    if ($i % 2 !== 0) {
      continue;          // on ignore les nombres impairs
    }
    if ($i > 6) {
      break;             // on stoppe au-dela de 6
    }
    echo "$i ";
  }
?>
RENDU

2 4 6

InstructionEffet
break;sort immédiatement de la boucle la plus proche ; le script reprend juste après
continue;abandonne le tour en cours et passe à l'itération suivante
break 2;sort de deux boucles imbriquées à la fois
continue 2;passe au tour suivant de la boucle extérieure

Dans une boucle imbriquée, break et continue n'agissent que sur la boucle la plus proche. Pour agir sur deux niveaux d'un coup, on précise un nombre : break 2.

⚡ EXO FLASH Le continue qui fige la page
  1. Dans continue_while.php, écrivez un while ($i <= 5) qui contient if ($i === 3) continue; avant le $i++. Que se passe-t-il au troisième tour ? (Sauvegardez votre travail avant de lancer.)
  2. Déplacez l'incrément avant le continue : la boucle termine et affiche 1 2 4 5 (les nombres de 1 à 5 sauf 3).
  3. Rejouez le même exercice avec un for : pourquoi le continue y est-il moins dangereux ?
Voir un début de correction 
<?php
  //  boucle infinie : $i vaut 3 pour toujours, le $i++ du bas est sauté
  $i = 1;
  while ($i <= 5) {
    if ($i === 3) { continue; }   // passe directement au test suivant
    echo $i . " ";
    $i++;
  }

  // ✅ version sûre : on incrémente avant de continuer
  $i = 1;
  while ($i <= 5) {
    if ($i === 3) { $i++; continue; }
    echo $i . " ";
    $i++;
  }
  // Avec un for, l'incrément est géré par la boucle elle-même :
  // continue déclenche quand même $i++, pas de figeage possible.
?>
06

Les pièges classiques

Trois erreurs reviennent dans presque tous les scripts qui utilisent des boucles. La première est la boucle infinie : on oublie l'incrément ($i++) et la condition ne devient jamais fausse, la page se fige. La deuxième est l'erreur de borne (off-by-one) : le compteur s'arrête un tour trop tôt ou un tour trop tard. La troisième est la boucle imbriquée mal maîtrisée : le tour intérieur est réexécuté intégralement à chaque tour extérieur.

PHP — Erreur de borne (off-by-one) 
<?php
  // Version correcte : 5 tours (1 a 5)
  for ($i = 1; $i <= 5; $i++) {
    echo "$i ";
  }
  echo "<br>";

  // Version hors limite : 4 tours seulement (1 a 4)
  for ($i = 1; $i < 5; $i++) {
    echo "$i ";
  }
?>
RENDU

1 2 3 4 5
1 2 3 4

Les boucles imbriquées permettent de construire des grilles et des figures. La boucle extérieure contrôle les lignes, la boucle intérieure contrôle les colonnes.

PHP — Boucles imbriquées : mini-grille 
<?php
  for ($ligne = 1; $ligne <= 4; $ligne++) {
    $etoiles = "";
    for ($col = 1; $col <= $ligne; $col++) {
      $etoiles .= "* ";
    }
    echo rtrim($etoiles) . "<br>";
  }
?>
RENDU

⚠️
La boucle infinie

Un while ($solde > 0) dont on oublie de retirer de l'argent ne s'arrête jamais : while (true) { … } est la forme la plus dangereuse. PHP a un timeout (souvent 30 à 60 secondes) qui coupe l'exécution, mais la page reste bloquée pendant ce temps. Relisez toujours votre incrément : $i++, $solde -= 5… Et méfiez-vous du continue placé avant l'incrément manuel d'un while : il rend la boucle infinie.

Exercices pratiques

EX 01 🔢 Compte à rebours
  1. Créez exo_rebours.php avec $compteur = 10;.
  2. Avec une boucle for, affichez 10, 9, 8… jusqu'à 1, sur une seule ligne.
  3. Ajoutez un message « Décollage ! » après la boucle.

Indice : partez de 10 et utilisez $compteur-- comme incrément : la condition $compteur >= 1 gère la fin.

EX 02 🧮 Table de multiplication
  1. Affichez la table de 7, de 1 à 10, sous la forme 7 x 1 = 7.
  2. Affichez ensuite les tables de 3 et de 4 avec une boucle imbriquée.
  3. Vérifiez qu'une ligne s'affiche par ligne de tableau (utilisez <br>).

Indice : la boucle extérieure gère le multiplicateur, l'intérieure le multiplicande de 1 à 10.

EX 03 🛒 Panier et total
  1. Créez un tableau associatif $panier avec trois produits et leur prix.
  2. Parcourez-le avec foreach ($panier as $produit => $prix) et affichez chaque ligne.
  3. Calculez le total du panier dans $total puis affichez-le.

Indice : accumulez dans $total += $prix; à chaque tour, puis formatez avec number_format().

EX 04 🔎 Filtre à nombres
  1. Parcourez un tableau de nombres de 1 à 20 avec for.
  2. Utilisez continue pour ignorer les multiples de 3 et break pour vous arrêter à 15.
  3. Enregistrez dans un tableau $retenus les nombres affichés.

Indice : le reste de la division s'obtient avec $i % 3 === 0 : c'est vrai quand $i est un multiple de 3.

08

Bilan & mini-glossaire

Ce que vous maîtrisez

  • Le principe d'une boucle : répéter un bloc tant qu'une condition est vraie
  • Le concept de répétition contrôlée : test, corps, incrément
  • La notion d'itération (un tour de boucle)
  • La syntaxe for ($i = 0; $i < N; $i++) et ses trois parties
  • La différence entre while (test avant) et do...while (test après)
  • foreach sur un tableau indexé ou associatif (valeur et clé)
  • Le rôle de break et continue, y compris dans les boucles imbriquées
  • Les trois pièges : boucle infinie, erreur de borne, imbrication
🚨
Erreurs fréquentes
  • Oublier l'incrément ($i++) dans un while → boucle infinie et page figée.
  • Se tromper de borne : $i < 5 donne 4 tours, $i <= 5 en donne 5.
  • Placer un continue avant l'incrément manuel d'un while → boucle infinie.
  • Modifier le compteur dans le corps du bloc et dans l'incrément → la boucle saute des tours.
  • Utiliser un for mal borné sur un tableau au lieu d'un foreach → erreurs « undefined offset ».

Mini-glossaire

Boucle
Structure qui répète un bloc de code tant qu'une condition reste vraie.
Itération
Un tour complet de la boucle (test, corps, incrément).
Répétition contrôlée
Répétition pilotée par un test et un compteur, jamais infinie par accident.
Initialisation
Instruction exécutée une seule fois avant le premier tour.
Incrément
Instruction exécutée après chaque tour pour faire avancer le compteur.
for
Boucle pour un nombre de tours connu, avec compteur intégré.
while
Boucle testée avant chaque tour : peut ne jamais s'exécuter.
do...while
Boucle testée après chaque tour : s'exécute au moins une fois.
foreach
Boucle dédiée au parcours des éléments d'un tableau.
