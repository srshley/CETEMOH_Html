01

Qu'est-ce que PHP ?

PHP (acronyme récursif de Hypertext Preprocessor) est un langage de script côté serveur conçu pour le web. Le fichier .php est envoyé au serveur, le serveur exécute le code, puis renvoie au navigateur le résultat — uniquement du HTML. Le visiteur ne voit jamais le code source PHP : il ne reçoit que le « plat ».

Un site statique (HTML pur) sert toujours la même page à tout le monde. Un site dynamique utilise PHP pour construire une page différente à chaque requête : page de profil, panier e-commerce, listing d'articles, message d'erreur personnalisé…

🍳
Analogie : le restaurant

Le navigateur est le client attablé, le serveur web est la cuisine, et PHP est le cuisinier. Le client envoie une commande (une requête HTTP) ; le cuisinier prépare le plat à partir des ingrédients stockés en réserve (la base de données) et sert l'assiette : du HTML. Le client ne voit jamais la recette, seulement le plat fini.

Un langage parmi d'autres

Chaque couche du web a son langage. Comprendre lequel fait quoi évite les confusions les plus courantes.

LangageExécutionRôle principalExemple
HTMLNavigateurStructure et contenu de la page<h1>Titre</h1>
CSSNavigateurPrésentation, couleurs, mise en page.btn { color: red; }
JavaScriptNavigateurInteractivité, animations, requêtes AJAXdocument.querySelector()
PHPServeurLogique métier, accès aux données, sessionsecho $total; ?>

La combinaison n'est donc pas une opposition : une page web moderne combine les quatre. PHP produit la structure, CSS la mise en forme, JavaScript l'interactivité, et PHP prépare les données côté serveur.

02

Syntaxe de base

Un script PHP est délimité par la balise ouvrante <?php et la balise fermante ?>. Tout ce qui se trouve entre ces deux balises est exécuté par le serveur ; tout ce qui est à l'extérieur est renvoyé tel quel au navigateur. Un fichier peut donc contenir du HTML et du PHP mélangés.

PHP — Premier script 
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Premier script</title>
</head>
<body>
  <?php
    $message = "Bonjour depuis le serveur !";
  ?>
  <h1>Bienvenue</h1>
  <p><?= $message ?></p>
</body>
</html>
RENDU

Bienvenue

Bonjour depuis le serveur !

Le point-virgule ; termine chaque instruction. Sans lui, PHP affiche une erreur de syntaxe. Les commentaires s'écrivent // en fin de ligne, # en fin de ligne, ou /* … */ sur plusieurs lignes.

📝
Le tag court <?= … ?>

La balise <?= … ?> est un raccourci d'echo : elle affiche une expression et se ferme automatiquement. Elle est idéale dans un template HTML :
<p>Bonjour <?= $nom ?></p> est exactement équivalent à <p>Bonjour <?php echo $nom; ?></p>.

Autre point à comprendre dès maintenant : PHP s'exécute de haut en bas. Une variable utilisée avant sa déclaration vaut null (avec un avertissement), et un echo placé plus haut dans le fichier sera envoyé plus haut dans la page. Les blocs PHP et HTML se succèdent donc comme les scènes d'un script : le serveur les joue dans l'ordre et ne livre au navigateur que le résultat.

⚡ EXO FLASH Balisage & point-virgule
  1. Créez mixte.php : un titre <h1> en HTML, puis un bloc <?php … ?> qui déclare $ville = "Nantes";.
  2. Affichez $ville plus bas avec le tag court <?= $ville ?> dans un <p>.
  3. Retirez le point-virgule, rechargez : lisez l'erreur de syntaxe et son numéro de ligne, puis remettez-le.
Voir un début de correction 
<?php
  $ville = "Nantes"; // sans le ; : Parse error … unexpected end of file
?>
<h1>Ma ville</h1>
<p>Bonjour depuis <?= $ville ?></p>
03

Variables & types de données

En PHP, une variable est un conteneur nommé qui commence obligatoirement par le symbole $. Son type n'est pas déclaré : il est déduit automatiquement de la valeur affectée (typage dynamique). Une variable affectée de l'entier 42 peut devenir la chaîne "42" le lendemain.

PHP — Variables et gettype() 
<?php
  $entier  = 42;
  $decimal = 3.14;
  $texte   = "Bonjour PHP";
  $vrai    = true;
  $tab     = [1, 2, 3];

  echo gettype($entier),  "<br>";   // integer
  echo gettype($decimal), "<br>";   // double
  echo gettype($texte),   "<br>";   // string
  echo gettype($vrai),    "<br>";   // boolean
  echo gettype($tab);                    // array
?>
RENDU

integer
double
string
boolean
array

La fonction gettype() renvoie le nom du type sous forme de chaîne. Pour un diagnostic complet (type + valeur + longueur), utilisez var_dump(), qui affiche le type et le contenu de la variable.

PHP — var_dump() 
<?php
  $prix = 19.90;
  $nom  = "Alice";

  var_dump($prix);
  var_dump($nom);
?>
RENDU

float(19.9)
string(5) "Alice"

Les six types à connaître

TypeExempleDescription
int42, -7Nombre entier, sans partie décimale
float3.14Nombre à virgule flottante
string"PHP", 'PHP'Chaîne de caractères
booltrue, falseValeur logique, vaut 1 ou 0
array[1, 2, 3]Tableau indexé ou associatif
nullnullAucune valeur / variable non initialisée

Les noms de variables sont sensibles à la casse : $age et $Age sont deux variables différentes. Ils ne peuvent ni commencer par un chiffre ni contenir d'espace ; on préfère donc le snake_case : $nom_utilisateur.

Attention à la coercion : avec des guillemets, "10" est une chaîne de 2 caractères ; sans guillemets, 10 est un entier. PHP sait convertir une chaîne numérique quand on fait un calcul ("14" + 1 donne bien 15), mais il le fait en silence — et pas toujours comme on l'attend ("14 petits" + 1 vaut 15 avec un avertissement). Vérifiez vos types avec gettype() plutôt que de les deviner.

⚡ EXO FLASH La variable qui change de type
  1. Déclarez $note = "14"; puis affichez gettype($note) : quel type obtenez-vous ?
  2. Écrivez $note = $note + 1; et refaites un var_dump() : le type a-t-il changé ? Pourquoi ?
  3. Créez $Note = "dix-huit"; et affichez les deux variables côte à côte : prouvez qu'elles sont indépendantes.
Voir un début de correction 
<?php
  $note = "14";
  var_dump($note);        // string(2) "14"
  $note = $note + 1;
  var_dump($note);        // int(15) — PHP a converti pour le calcul

  $Note = "dix-huit";
  echo $note . " / " . $Note;  // 15 / dix-huit — 2 variables distinctes
?>
04

Affichage : echo, print & printf

Trois fonctions permettent d'écrire une valeur dans la page : echo (la plus utilisée), print (similaire) et printf() (formatage avec des gabarits). echo accepte plusieurs arguments séparés par des virgules, et accepte n'importe quel type de valeur.

PHP — echo, print, printf 
<?php
  $nom = "Alice";
  $age = 25;

  echo "Bonjour ", $nom, " !<br>";
  print "Age : " . $age . "<br>";
  printf("Nom : %s (%d ans)<br>", $nom, $age);
  echo "Interpolation : $nom a $age ans";
?>
RENDU

Bonjour Alice !
Age : 25
Nom : Alice (25 ans)
Interpolation : Alice a 25 ans

Dans une chaîne entre guillemets doubles, PHP interprète les variables : on parle d'interpolation. Pour concaténer un calcul, on utilise l'opérateur point .. La fonction printf() utilise des gabarits : %s pour une chaîne, %d pour un entier, %.2f pour un décimal à deux chiffres.

💡
Choisir entre echo et print

echo accepte plusieurs arguments et est légèrement plus rapide : c'est le choix par défaut. print renvoie toujours 1, ce qui permet de l'utiliser dans une expression. Les deux se terminent par un point-virgule. Réservez printf() aux tableaux formatés (prix alignés, dates, pourcentages).

Les accolades dans l'interpolation

Dans une chaîne entre guillemets doubles, "$nom a $age ans" fonctionne pour des variables simples. Dès qu'il y a un tableau ou une propriété, il faut encercler l'expression d'accolades : "{$eleve['note']}" et non "$eleve['note']" (qui provoque une erreur de parsing). Réflexe à prendre tout de suite : les accolades marchent toujours.

⚡ EXO FLASH Trois façons d'afficher la même fiche
  1. Avec $produit = "souris"; et $prix = 24.9;, affichez « souris à 24.90 EUR » avec printf() (indices %s et %.2f).
  2. Refaites le même rendu avec echo et une concaténation (.), puis avec une interpolation entre guillemets doubles.
  3. Comparez : quelle méthode affiche 24.90 et non 24.9 ? Que se passe-t-il si vous passez $prix dans %s au lieu de %.2f ?
Voir un début de correction 
<?php
  $produit = "souris";
  $prix    = 24.9;

  printf("%s à %.2f EUR<br>", $produit, $prix);      // souris à 24.90 EUR
  echo $produit . " à " . number_format($prix, 2) . " EUR<br>";
  echo "{$produit} à " . sprintf('%.2f', $prix) . " EUR";
?>
05

Configuration & outils

Pour écrire du PHP, il faut un serveur web local et un éditeur de code. XAMPP installe en un clic Apache, PHP et MySQL : déposez vos fichiers dans htdocs/ et ouvrez http://localhost/mon-fichier.php. Côté éditeur, VS Code avec l'extension PHP Intelephense (autocomplétion, diagnostics, navigation dans le code) devient indispensable dès la première séance.

La fonction phpinfo() affiche l'intégralité de la configuration PHP : version, extensions activées, directives du php.ini. Elle sert à vérifier que l'environnement est complet avant de commencer.

PHP — phpinfo() 
<?php
  // info.php — à déposer dans htdocs/info.php
  phpinfo();          // configuration complète de PHP
?>

06

Premières bonnes pratiques

Un code lisible est un code qu'on relit sans hésiter. Quatre réflexes suffisent pour démarrer proprement : indenter avec 4 espaces (jamais des tabulations mélangées), commenter les sections utiles, nommer les variables de façon explicite en snake_case, et garder un seul concept par ligne de code.

PHP — Script bien indenté 
<?php
  /**
   * Fiche produit
   */

  // Données de la fiche
  $nom   = "Clavier mécanique";
  $prix  = 79.90;
  $stock = 12;

  // Calcul du prix TTC
  $tva   = 0.20;
  $total = $prix * (1 + $tva);

  // Affichage
  echo "Produit : " . $nom . "<br>";
  echo "Prix HT : " . $prix . " EUR<br>";
  echo "Total TTC : " . round($total, 2) . " EUR<br>";
  echo "Stock : " . $stock . " unites";
?>
RENDU

Produit : Clavier mécanique
Prix HT : 79.9 EUR
Total TTC : 95.88 EUR
Stock : 12 unites

⚠️
Ne fermez pas la balise ?> en fin de fichier

Si un fichier PHP se termine par ?>, PHP envoie les caractères qui suivent (souvent un saut de ligne final) directement au navigateur. Cela provoque des messages du type headers already sent et casse les sessions. La règle : on ouvre <?php en début de fichier, on ne referme jamais la balise à la fin.

Enfin, pensez à la sécurité dès le départ : n'affichez jamais une saisie utilisateur brute dans la page, et préférez les quotes simples '…' quand la chaîne ne contient pas de variable à interpoler — c'est plus rapide et plus sûr.

Exercices pratiques

EX 01 🚀 Mon premier script
  1. Créez hello.php dans le dossier htdocs/ de XAMPP.
  2. Affichez un <h1> « Mon premier PHP » puis un echo « Bonjour ! ».
  3. Ouvrez http://localhost/hello.php : le texte doit s'afficher dans la page, pas dans le code source.

Indice : le HTML se place autour du bloc <?php … ?>, pas l'inverse.

EX 02 🔤 Variables & types
  1. Déclarez $prenom, $age et $langage avec des valeurs de types différents.
  2. Affichez une phrase qui combine les trois (concaténation avec .).
  3. Utilisez var_dump() sur chaque variable pour vérifier le type obtenu.

Indice : var_dump() affiche le type entre parenthèses, comme string(5) "Alice".

EX 03 🔍 Deviner les types
  1. Créez cinq variables : $i = 10;, $d = 2.5;, $s = "10";, $b = false;, $a = [1, 2];.
  2. Prévoyez le résultat de gettype() pour chacune avant de lancer le script.
  3. Affichez les cinq résultats et comparez avec vos prédictions.

Indice : "10" est une chaîne, pas un nombre : PHP ne devine pas l'intention.

EX 04 🏷️ Fiche produit
  1. Déclarez $nom, $prix_ht (ex. 79.90) et $tva (0.20).
  2. Calculez le prix TTC dans une variable $total puis affichez-le avec round($total, 2).
  3. Affichez le résultat dans une balise <p> et vérifiez qu'il vaut 95.88.

Indice : $prix_ht * (1 + $tva) — les parenthèses changent le résultat.

  • La syntaxe <?php … ?> et le tag court <?= … ?>

🚨
Erreurs fréquentes
  • Oublier le point-virgule à la fin d'une instruction → erreur de syntaxe.
  • Oublier le $ devant une variable → PHP la traite comme une constante et affiche « undefined variable ».
  • Écrire <?PHP ou <?php avec une faute de frappe → le code s'affiche en texte brut dans la page.
  • Fermer la balise ?> en fin de fichier → espaces parasites envoyés avant les headers.
  • Écrire <?php echo $x; ?> dans une balise <pre> sans échapper → le HTML est interprété au lieu d'être affiché.
