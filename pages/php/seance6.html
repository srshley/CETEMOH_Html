01

Qu'est-ce qu'un tableau ?

Un tableau (array) stocke plusieurs valeurs dans une seule variable. Au lieu de déclarer $fruit1, $fruit2, $fruit3, on écrit un seul $fruits qui contient tout. Chaque valeur repose dans un compartiment repéré par une clé ; l'ensemble des clés et des valeurs forme le tableau.

Le cas le plus simple est le tableau indexé : les clés sont des numéros attribués automatiquement, à partir de 0. La première valeur est donc à l'indice 0, la deuxième à l'indice 1, et ainsi de suite.

PHP — Tableau indexé 
<?php
  $fruits = ["pomme", "banane"];

  echo $fruits[0];           // pomme
  echo "<br>" . $fruits[1];  // banane

  $fruits[] = "cerise";      // ajout automatique a la fin
  echo "<br>" . count($fruits); // 3
?>
RENDU

pomme
banane
3

🗄️
Analogie : la boîte à compartiments numérotés

Un tableau est une boîte divisée en compartiments numérotés : chaque compartiment contient une valeur, et son numéro (la clé) permet d'y mettre la main directement. Le premier compartiment porte le numéro 0 — une convention qui surprendra au début, mais que l'on retrouve dans presque tous les langages.

02

Tableaux associatifs

Dans un tableau associatif, on choisit soi-même les clés au lieu de laisser PHP les numéroter. C'est la forme idéale pour décrire un objet du monde réel — un utilisateur, un produit, un paramétrage — : chaque clé porte un nom explicite ("nom", "age", "prix") et sa valeur lui répond.

PHP — Tableau associatif 
<?php
  $personne = [
    "nom"   => "Alice",
    "age"   => 30,
    "ville" => "Rabat"
  ];

  echo $personne["nom"];          // Alice
  echo "<br>" . $personne["age"]; // 30

  $personne["age"] = 31;          // modification
  echo "<br>" . $personne["age"]; // 31
?>
RENDU

Alice
30
31

La flèche => se lit « a pour valeur » : "age" => 30 se lit « la clé age a pour valeur 30 ». Un même tableau peut mélanger chaînes et nombres : le type du contenu n'a aucune importance.

💡
Choisissez des clés explicites

Préférez $personne["age"] à $personne[1] : le code se lit tout seul et reste compréhensible six mois plus tard. Des clés nommées comme des variables courantes (nom, prix, email) rendent un script relié à une base de données beaucoup plus facile à maintenir.

⚡ EXO FLASH Fiche produit
  1. Déclarez dans exo_assoc.php un tableau associatif $produit avec trois clés : "nom", "prix" et "stock".
  2. Affichez $produit["nom"] puis $produit["prix"], séparés par un <br>.
  3. Ajoutez une clé "remise" de valeur 10 : prévoyez ce que renverra count($produit) (4 ?) puis vérifiez.
Voir un début de correction 
<?php
  $produit = ["nom" => "Clavier", "prix" => 45, "stock" => 7];
  echo $produit["nom"] . "<br>" . $produit["prix"];
  $produit["remise"] = 10;
  echo "<br>" . count($produit);
?>
03

Tableaux multidimensionnels

Un tableau peut contenir d'autres tableaux : on parle de tableau à plusieurs dimensions, ou « tableau de tableaux ». C'est la structure naturelle d'un catalogue de produits, d'une liste d'utilisateurs, d'une grille horaire : une liste où chaque ligne est elle-même un tableau associatif.

PHP — Catalogue à deux dimensions 
<?php
  $catalogue = [
    ["nom" => "Clavier", "prix" => 45],
    ["nom" => "Souris",  "prix" => 25],
    ["nom" => "Ecran",   "prix" => 180]
  ];

  foreach ($catalogue as $produit) {
    echo $produit["nom"] . " : " . $produit["prix"] . " EUR<br>";
  }
?>
RENDU

Clavier : 45 EUR
Souris : 25 EUR
Ecran : 180 EUR

Les tableaux multidimensionnels sont massivement utilisés avec foreach : la boucle extérieure donne une ligne entière (ici $produit), et on lit ses champs comme un tableau associatif ordinaire.

📝
L'accès imbriqué, crochet après crochet

Pour atteindre une valeur en profondeur, on empile les crochets de l'extérieur vers l'intérieur : $catalogue[1]["prix"] désigne le prix (clé "prix") du deuxième produit (indice 1). Lire de gauche à droite : « la deuxième ligne, puis la colonne prix ».

04

Parcourir un tableau

Le principe est l'outil roi : foreach lit chaque élément, du premier au dernier, sans risque de dépasser la fin. Deux formes existent : valeur seule (as $valeur) et clé + valeur (as $cle => $valeur). La fonction count() renvoie quant à elle le nombre d'éléments.

MéthodeCe qu'elle fait
foreach ($t as $v)parcourt chaque valeur du tableau, une par un
foreach ($t as $k => $v)parcourt chaque paire clé / valeur
count($t)renvoie le nombre d'éléments du tableau
array_keys($t)renvoie un tableau contenant toutes les clés
array_values($t)renvoie un tableau contenant toutes les valeurs
PHP — foreach, count, clés et valeurs 
<?php
  $user = ["nom" => "Ali", "age" => 25, "role" => "admin"];

  echo count($user) . " champs<br>";
  echo implode(", ", array_keys($user)) . "<br>";
  echo implode(", ", array_values($user)) . "<br>";

  foreach ($user as $cle => $valeur) {
    echo "$cle = $valeur<br>";
  }
?>
RENDU

3 champs
nom, age, role
Ali, 25, admin
nom = Ali
age = 25
role = admin

Sur un tableau indexé, la forme clé + valeur donne l'indice dans $cle : pratique pour numéroter des lignes ("Élément " . ($cle + 1)). Si la clé ne sert à rien, la forme valeur seule est plus lisible.

⚡ EXO FLASH Clés, valeurs et total
  1. Déclarez dans exo_parcours.php un tableau associatif $notes reliant trois matières à leur note.
  2. Parcourez-le avec foreach ($notes as $matiere => $note) et affichez « Maths : 12 » sur chaque ligne.
  3. Additionnez les notes dans un accumulateur : prévoyez la somme et le count($notes) avant de vérifier.
Voir un début de correction 
<?php
  $notes = ["Maths" => 12, "Français" => 15, "HP" => 9];
  $total = 0;
  foreach ($notes as $matiere => $note) {
    echo "$matiere : $note<br>";
    $total += $note;
  }
  echo count($notes) . " notes, total $total";
?>
05

Ajouter / modifier / supprimer

Un tableau est modifiable à tout moment. La syntaxe courte $t[] = $x ajoute un élément à la fin sans se soucier des indices. Écrire dans une clé existante la modifie ; unset() supprime un élément ou un tableau entier. Les fonctions array_push, array_pop, array_shift et array_unshift agissent sur les deux extrémités.

PHP — Manipuler un tableau 
<?php
  $taches = ["Nettoyer", "Coder", "Dormir"];

  array_push($taches, "Lire");      // ajoute a la fin
  array_unshift($taches, "Boire");  // ajoute au debut
  $derniere = array_pop($taches);   // retire la derniere
  $premiere = array_shift($taches); // retire la premiere

  echo implode(" | ", $taches);
  echo "<br>Retirees : $derniere et $premiere";

  unset($taches[0]);                // supprime par cle
  echo "<br>Restantes : " . count($taches);
?>
RENDU

Nettoyer | Coder | Dormir
Retirees : Lire et Boire
Restantes : 2

InstructionEffet
$t[] = "x";ajoute un élément à la fin, avec le prochain indice disponible
$t[$cle] = "y";modifie l'élément existant (ou le crée à cette clé)
array_push($t, "x")ajoute à la fin — équivalent à la syntaxe courte
array_unshift($t, "x")ajoute au début et renumérote les indices
array_pop($t)retire et renvoie le dernier élément
array_shift($t)retire et renvoie le premier élément
unset($t[$cle])supprime l'élément, sans réindexer le reste

Après unset($taches[0]), les indices ne se recalculent pas : le tableau peut présenter un « trou » (clés 1, 2 sans 0). C'est sans conséquence pour foreach, mais il faut le savoir si on compte les clés à la main.

06

Fonctions de conversion

Il arrive souvent qu'une donnée arrive sous forme de chaîne (un paramètre d'URL, un CSV) et doive devenir un tableau, ou l'inverse. explode() découpe une chaîne en tableau, implode() recolle un tableau en chaîne. in_array() et array_key_exists() vérifient l'appartenance, et json_encode() transforme une valeur PHP en chaîne JSON.

PHP — Chaînes, tableaux et JSON 
<?php
  // explode / implode
  $csv = "PHP,HTML,CSS";
  $langages = explode(",", $csv);
  echo $langages[1];                        // HTML
  echo "<br>" . implode(" + ", $langages);  // PHP + HTML + CSS

  // tests d'appartenance
  $roles = ["admin", "lecteur"];
  echo "<br>" . (in_array("admin", $roles) ? "role connu" : "role inconnu");

  $config = ["theme" => "sombre", "taille" => 14];
  echo "<br>" . (array_key_exists("taille", $config) ? "cle presente" : "cle absente");

  // export JSON
  echo "<br>" . json_encode($config);
?>
RENDU

HTML
PHP + HTML + CSS
role connu
cle presente
{"theme":"sombre","taille":14}

💡
Pourquoi le JSON ?

json_encode() est le pont vers le monde extérieur : envoyer des données à JavaScript, stocker une configuration dans un fichier, répondre à une requête API. La fonction réciproque, json_decode(), transforme la chaîne JSON en tableau PHP. Notez les guillemets doubles produits autour des clés : c'est le format JSON convenu.

Attention : explode() ne nettoie rien — découper "a, b" avec la virgule seule donne ["a", " b"], un espace restant collé au deuxième élément. Passez alors trim() sur chaque morceau (par exemple array_map('trim', $t)) ou prenez ", " comme séparateur. explode() accepte aussi un troisième argument qui limite le nombre de découpages, utile pour laisser intact le reste d'une ligne à plusieurs champs.

Exercices pratiques

EX 01 🛒 Panier de courses
  1. Créez exo_courses.php avec un tableau indexé de 5 articles.
  2. Affichez chaque article avec foreach, précédé de son numéro (1 à 5).
  3. Affichez le nombre total d'articles avec count().

Indice : la forme foreach ($courses as $indice => $article) vous donne l'indice ; ajoutez 1 pour un affichage humain.

EX 02 🧑 Fiche étudiant
  1. Créez un tableau associatif $etudiant avec les clés "nom", "age" et "email".
  2. Affichez chaque clé et sa valeur avec foreach sous la forme nom = Alice.
  3. Modifiez "age", puis ajoutez une clé "moyenne" et vérifiez avec array_key_exists().

Indice : $etudiant["age"] = 21; modifie la valeur ; $etudiant["moyenne"] = 14.5; crée la clé.

EX 03 📚 Catalogue et total
  1. Créez un tableau multidimensionnel de 3 produits, chacun avec "nom" et "prix".
  2. Bouclez dessus avec foreach pour afficher « nom : prix EUR » par produit.
  3. Calculez le total de tous les prix et affichez-le.

Indice : dans la boucle, $produit["prix"] suffit ; accumulez avec $total += $produit["prix"];.

EX 04 🔄 CSV ↔ tableau
  1. Partez de la chaîne $csv = "PHP,HTML,CSS,SQL"; et découpez-la avec explode().
  2. Vérifiez que "CSS" fait partie de la liste avec in_array().
  3. Recollez le tableau en chaîne avec implode() séparée par « · », puis exportez-la en JSON avec json_encode().

Indice : implode(" · ", $langages) ; pour le JSON, json_encode($langages) renvoie ["PHP","HTML","CSS","SQL"].

08

Bilan & mini-glossaire

Ce que vous maîtrisez

  • Regrouper plusieurs valeurs dans une seule variable avec un array
  • Les tableaux indexés, dont les clés commencent à 0
  • Les tableaux associatifs et l'accès par clé nommée
  • Les tableaux multidimensionnels et l'accès imbriqué $t[0]["prix"]
  • Parcourir avec foreach (valeur, puis clé => valeur)
  • count(), array_keys(), array_values()
  • Ajouter ($t[] = ), modifier ($t[$k] =), supprimer (unset, array_pop…)
  • Convertir entre chaînes et tableaux (explode / implode) et exporter en JSON
🚨
Erreurs fréquentes
  • Oublier que les indices commencent à 0 : sur un tableau de 3 éléments, le dernier est $t[2].
  • Lire $t[3] hors limites → avertissement « undefined array key ».
  • Utiliser $t["nom"] sur un tableau indexé (ou l'inverse) → la clé n'existe pas.
  • Croire que unset() réindexe le tableau : il laisse un « trou » dans les clés.
  • Confondre l'élément et son indice dans foreach ($t as $v) : $v est la valeur, pas le numéro.

Mini-glossaire

Tableau
Variable contenant une collection de valeurs, repérées par des clés.
Tableau indexé
Tableau dont les clés sont des numéros automatiques (0, 1, 2…).
Tableau associatif
Tableau dont les clés sont personnalisées, choisies par le développeur.
Multidimensionnel
Tableau contenant d'autres tableaux (tableau de tableaux).
Clé
Identifiant qui repère un élément dans le tableau.
unset()
Supprime une variable ou un élément particulier d'un tableau.
implode / explode
Convertit un tableau en chaîne, et une chaîne en tableau.
json_encode()
Sérialise une valeur PHP en chaîne JSON, exportable vers JavaScript.
in_array()
Teste si une valeur existe dans un tableau (renvoie un booléen).
