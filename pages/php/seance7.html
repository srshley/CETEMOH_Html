01

Panorama des fonctions array_*

PHP propose plus de 80 fonctions dédiées aux tableaux. Pas besoin de les connaître toutes par cœur : il faut surtout repérer les cinq familles qui couvrent 95 % des besoins du quotidien. Chaque fonction suit une convention claire : elle reçoit le tableau en premier (ou dernier) argument et renvoie soit un nouveau tableau, soit un booléen quand elle modifie le tableau original.

CatégorieFonctions principalesRôle
Parcourirforeach, array_keys, array_values, countExtraire les clés, les valeurs, compter les éléments
Filtrerarray_filter, array_slice, array_uniqueNe garder qu'une partie des éléments
Triersort, rsort, asort, ksort, usortRéordonner les éléments selon un critère
Transformerarray_map, array_reduce, array_flip, array_reverseProduire un nouveau tableau à partir de l'ancien
Chercherin_array, array_search, array_key_existsTester la présence d'une valeur ou d'une clé
📝
Deux conventions à ne pas confondre

Les fonctions de tri (sort, asort…) agissent par référence : elles modifient le tableau passé en argument et renvoient un booléen. Les autres (array_map, array_slice…) renvoient un nouveau tableau sans toucher à l'original. Écrire $t = sort($t); est une erreur : sort renvoie true, pas le tableau trié.

02

Trier un tableau

Les quatre fonctions de base se distinguent par deux questions : tri-t-on sur les valeurs ou les clés ? et dans quel ordre ? Les tableaux indexés utilisent sort / rsort ; les tableaux associatifs utilisent asort (sur valeurs) ou ksort (sur clés).

PHP — sort sur une liste de prix 
<?php
  $prix = [12.99, 4.50, 29.90, 7.25];
  sort($prix);
  foreach ($prix as $p) {
    echo "$p EUR<br>";
  }
?>
RENDU

4.5 EUR
7.25 EUR
12.99 EUR
29.9 EUR

Sur un tableau associatif, asort trie sur les valeurs en conservant les clés, tandis que ksort trie sur les clés. Pour un ordre personnalisé (par exemple trier par longueur), on passe une fonction de comparaison à usort : elle retourne négatif, 0 ou positif selon l'ordre voulu.

PHP — asort, ksort et usort 
<?php
  $stock = ["cerise" => 8, "pomme" => 3, "kiwi" => 12];
  asort($stock);   // trie sur les valeurs
  foreach ($stock as $produit => $n) {
    echo "$produit : $n<br>";
  }
  $mots = ["kiwi", "banane", "poire"];
  usort($mots, fn($a, $b) => strlen($a) - strlen($b));
  echo implode(", ", $mots);
?>
RENDU

pomme : 3
cerise : 8
kiwi : 12
kiwi, poire, banane

📝
sort réindexe, asort conserve

sort() détruit les clés d'origine et renumérote à partir de 0 : le lien entre une clé et sa valeur est perdu. Sur un tableau associatif, utilisez toujours asort ou ksort, qui conservent l'association clé → valeur. C'est l'une des erreurs les plus fréquentes sur les tableaux PHP.

⚡ EXO FLASH Trier sans perdre les clés
  1. Déclarez dans exo_tri.php un tableau associatif $eleves liant trois noms d'élèves à leur moyenne.
  2. Prévoyez l'ordre obtenu par sort($eleves), puis par asort($eleves), et vérifiez lequel garde le lien nom → moyenne.
  3. Retournez le tri décroissant avec arsort() et affichez chaque ligne « nom : moyenne ».
Voir un début de correction 
<?php
  $eleves = ["Ali" => 12, "Sara" => 15, "Karim" => 9];
  asort($eleves);
  foreach ($eleves as $nom => $moy) {
    echo "$nom : $moy<br>";
  }
?>
03

Filtrer & transformer

Trois fonctions forment le trio « carte » des tableaux : array_filter garde les éléments qui satisfont un test, array_map transforme chaque élément, et array_reduce condense tout le tableau en une seule valeur (un total, une concaténation, un maximum…). Les trois utilisent un callback, souvent une fonction fléchée.

PHP — filter, map, reduce sur un panier 
<?php
  $panier = [19.99, 35.00, 7.50, 120.00];
  // 1. Garder les articles a plus de 20 EUR
  $chers = array_filter($panier, fn($p) => $p > 20);
  echo count($chers) . " articles chers<br>";
  // 2. Appliquer la TVA a chaque prix
  $ttc = array_map(fn($p) => $p * 1.2, $panier);
  echo "Premier prix TTC : " . $ttc[0] . "<br>";
  // 3. Total du panier
  $total = array_reduce($panier, fn($acc, $p) => $acc + $p, 0);
  echo "Total : $total EUR";
?>
RENDU

2 articles chers
Premier prix TTC : 23.988
Total : 182.49 EUR

💡
array_filter conserve les clés d'origine

Contrairement à sort, array_filter ne réindexe pas : filtrer [10, 20, 30] sur « > 15 » donne un tableau dont les clés sont 1 et 2. Un foreach dessus fonctionne parfaitement, mais si vous avez besoin d'indices consécutifs (JSON, boucle for), ajoutez array_values($resultat) après le filtre. Et sans callback, array_filter($t) supprime simplement tous les éléments « falsy » (0, "", null, []) — pratique pour nettoyer un formulaire, piégeux si le zéro est une valeur légitime.

04

Fusionner & découper

array_merge concatène plusieurs tableaux (les clés numériques sont renumérotées, les clés texte sont écrasées en cas de doublon). array_combine fabrique un tableau associatif à partir d'un tableau de clés et d'un tableau de valeurs de même longueur.

PHP — merge et combine 
<?php
  $info1 = ["nom" => "Ali", "age" => 25];
  $info2 = ["ville" => "Rabat"];
  echo json_encode(array_merge($info1, $info2));
  echo "<br>";  $noms = ["Ali", "Sara", "Karim"];
  $ages = [25, 31, 19];
  echo json_encode(array_combine($noms, $ages));
?>
RENDU

{"nom":"Ali","age":25,"ville":"Rabat"}
{"Ali":25,"Sara":31,"Karim":19}

Pour extraire une portion de tableau, array_slice($t, $debut, $nb) renvoie une copie sans toucher à l'original, tandis que array_splice retire la portion du tableau source (et peut la remplacer). array_unique supprime les doublons de valeurs.

PHP — slice, splice, unique 
<?php
  $journees = ["sam", "dim", "lun", "mar", "mer"];
  $weekend = array_slice($journees, 0, 2);
  echo implode(" ", $weekend) . "<br>";   // sam dim
  array_splice($journees, 0, 2);          // retire sam, dim
  echo implode(" ", $journees) . "<br>";  // lun mar mer
  $notes = [12, 15, 12, 9, 15];
  echo implode(" ", array_unique($notes)); // 12 15 9
?>
RENDU

sam dim
lun mar mer
12 15 9

⚠️
array_unique conserve les clés

Comme array_filter, array_unique garde les clés du premier doublon rencontré : [12, 15, 12] devient [0 => 12, 1 => 15]. Chaînez avec array_values() pour réindexer avant un json_encode ou une boucle for, sinon le JSON produit un objet au lieu d'un tableau.

⚡ EXO FLASH Fusionner et découper
  1. Dans exo_fusion.php, fusionnez [10, 12] et [15] avec array_merge() et affichez le count() du résultat.
  2. Découpez ce tableau avec array_slice($toutes, 1) et affichez la portion obtenue.
  3. Prévoyez ce que renvoie array_unique([10, 12, 10]), puis vérifiez en affichant les valeurs avec implode().
Voir un début de correction 
<?php
  $toutes = array_merge([10, 12], [15]);
  echo count($toutes) . "<br>";
  echo implode(",", array_slice($toutes, 1)) . "<br>";
  echo implode(",", array_unique([10, 12, 10]));
?>
05

Chercher & vérifier

in_array($v, $t) teste la présence d'une valeur, array_search($v, $t) renvoie la clé du premier élément trouvé (false sinon), et array_key_exists($k, $t) teste la présence d'une clé. Ces trois fonctions sont le socle de la validation de données entrantes.

PHP — in_array, array_search, array_key_exists 
<?php
  $roles  = ["admin", "editeur", "lecteur"];
  $cleFam = ["Alice" => "0612", "Mehdi" => "0789"];
  if (in_array("admin", $roles)) {
    echo "Role admin present<br>";
  }
  $pos = array_search("Mehdi", array_keys($cleFam));
  echo "Position de Mehdi : $pos<br>";

  if (array_key_exists("Alice", $cleFam)) {
    echo "Alice : " . $cleFam["Alice"];
  }
?>
RENDU

Role admin present
Position de Mehdi : 1
Alice : 0612

Passons au comparatif des trois outils de vérification : à première vue isset et array_key_exists semblent interchangeables, mais leur comportement diverge sur les valeurs null et sur le type de comparaison des valeurs. Quand vous validez une entrée utilisateur (venant d'un formulaire), ajoutez systématiquement le troisième argument strict à in_array : sans lui, in_array("12", [12]) vaut true, puisque la chaîne "12" « égale » l'entier 12 en comparaison lâche. La forme in_array($v, $t, true) exige la même valeur et le même type.

OutilCe qu'il vérifieComportement face à nullCas d'usage
isset($t["k"])la clé existe et n'est pas nullvaut false si la valeur est nulltests rapides sur des variables / superglobales
array_key_exists("k", $t)la clé existe, valeur y compris nullvaut true même si la valeur est nullvérifier strictement la présence d'une clé
in_array($v, $t)la valeur existe parmi les élémentscompare avec == (ou === en mode strict)valider une option parmi une liste blanche

Méfiez-vous d'array_search() : elle renvoie la clé du premier élément trouvé, donc 0 — une valeur falsy — si la cible est en tête du tableau, et false seulement si elle est absente. Testez toujours avec !== false, sinon une clé 0 légitime est confondue avec un échec. Comme in_array(), elle compare lâchement par défaut : passez true en troisième argument pour imposer le même type.

06

Tableaux & JSON

JSON est le format universel d'échange : API, cookies, fichiers de configuration. json_encode($tableau) transforme un tableau en chaîne JSON ; json_decode($json, true) fait l'inverse, et le second argument true demande un tableau associatif plutôt qu'un objet.

PHP — json_encode / json_decode 
<?php
  $eleve = ["nom" => "Sara", "notes" => [12, 15, 9]];
  $json = json_encode($eleve);
  echo $json . "<br>";
  $tab = json_decode($json, true);
  echo $tab["nom"] . " : " . $tab["notes"][1];
?>
RENDU

{"nom":"Sara","notes":[12,15,9]}
Sara : 15

⚠️
Toujours vérifier avec json_last_error

En cas d'échec, json_encode et json_decode renvoient tous deux null… sans message d'erreur. Interrogez json_last_error_msg() juste après l'appel : un JSON mal formé décodé sans vérification produit un tableau null dont l'exploitation plante plus loin, ce qui rend le bug très difficile à localiser. Dernier détail : la conversion ne capture que chaînes, nombres, booléens, sous-tableaux et null — pas les fonctions.

07

Exercices pratiques

EX 01 📈 Classement des prix
  1. Créez exo_prix.php avec un tableau de six prix non triés.
  2. Affichez-les du moins cher au plus cher, puis du plus cher au moins cher.
  3. Reconstruisez le même tableau associatif avec des noms de produits et triez-le sur les valeurs sans perdre les clés.

Indice : sort / rsort pour la liste, puis asort pour l'associatif — sort réindexerait les clés.

EX 02 🛒 Panier filtré
  1. Partez d'un panier : tableau associatif produit → prix (au moins 5 lignes).
  2. Avec array_filter, gardez les articles à moins de 10 EUR.
  3. Avec array_map, calculez le prix TTC (+20 %) des articles restants.
  4. Avec array_reduce, affichez le total TTC, formaté avec number_format.

Indice : enchaînez array_reduce(array_map(...), ...) — le résultat d'une fonction est un tableau utilisable par la suivante.

EX 03 🔎 Liste blanche
  1. Définissez une liste blanche de pages autorisées : ["accueil", "profil", "contact"].
  2. Une variable $page simule une entrée utilisateur (testez "profil" puis "pirate").
  3. Affichez « Page autorisée » ou « Accès refusé » avec in_array en mode strict.

Indice : in_array($page, $blanc, true) — le mode strict évite les égalités de type surprenantes.

EX 04 💾 Sauvegarde JSON
  1. Créez un tableau multidimensionnel : deux élèves, chacun avec nom, classe et tableau de notes.
  2. Encodez-le en JSON et affichez la chaîne obtenue.
  3. Décodez-la en tableau associatif, puis affichez la moyenne de chaque élève.

Indice : passez true en second argument de json_decode, et testez json_last_error_msg() avant d'exploiter le résultat.

08

Bilan & mini-glossaire

Ce que vous maîtrisez

  • Les cinq familles de fonctions array_* et leurs conventions
  • Trier valeur ou clé : sort, rsort, asort, arsort, ksort
  • Un tri personnalisé avec usort et une fonction de comparaison
  • Filtrer, transformer, réduire : array_filter, array_map, array_reduce
  • Fusionner et découper : array_merge, array_combine, array_slice, array_splice, array_unique
  • Chercher : in_array (strict), array_search, array_key_exists, isset
  • Convertir vers et depuis JSON avec vérification de json_last_error
  • Les pièges clés : sort réindexe, array_filter/array_unique conservent les clés
🚨
Erreurs fréquentes
  • Écrire $t = sort($t); → $t devient true, le tableau est perdu.
  • Utiliser sort sur un tableau associatif → les clés produit → prix sont détruites.
  • Oublier que array_filter conserve les clés → un JSON qui devient un objet.
  • Decoder un JSON sans vérifier json_last_error → plantage différé sur un null.
  • Utiliser isset($t["k"]) pour vérifier une clé de valeur null → faux négatif ; utilisez array_key_exists.

Mini-glossaire

Callback
Fonction passée en argument à une autre fonction (souvent une fléchée fn()).
array_filter
Garde les éléments qui satisfont un test ; conserve les clés d'origine.
array_map
Applique une transformation à chaque élément et renvoie un nouveau tableau.
array_reduce
Condense le tableau en une seule valeur via un accumulateur.
array_merge
Concatène plusieurs tableaux ; les clés texte en doublon sont écrasées.
array_slice / array_splice
Extraire une portion (copie) / retirer et remplacer une portion (modification).
array_key_exists
Vérifie la présence d'une clé, même si sa valeur est null.
json_encode / json_decode
Convertit un tableau en chaîne JSON, et inversement (avec true pour un tableau associatif).
