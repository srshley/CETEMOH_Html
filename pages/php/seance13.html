01

Classes et objets

La Programmation Orientée Objet (POO) regroupe dans une même entité les données d'un problème et les traitements qui s'y rapportent. Une classe est un modèle abstrait qui décrit ce que possèdent et savent faire ses instances ; un objet est une instance concrète de cette classe, créée avec new. À partir d'une même classe, on peut créer autant d'objets que nécessaire : chacun conserve ses propres valeurs tout en partageant le même code.

PHP — class & new 
<?php
  class Personne {
  }

  $a = new Personne();   // 1er objet
  $b = new Personne();   // un 2e objet, indépendant
  var_dump($a instanceof Personne);
?>
RENDU

bool(true)

🏗️
Analogie : le plan et la maison

La classe est le plan de l'architecte : elle définit où seront les pièces, mais personne ne peut y habiter. L'objet est la maison construite : concrète, habitable, avec ses propres meubles (ses valeurs). Un même plan permet de construire mille maisons différentes.

02

Propriétés, méthodes & $this

Une propriété est une variable déclarée dans la classe (ex. public $nom;). Une méthode est une fonction définie dans la classe. À l'intérieur d'une méthode, la variable magique $this désigne l'objet courant qui a appelé le code : c'est lui qu'on lit ou modifie.

PHP — propriétés & $this 
<?php
  class Personne {
    public $nom = "Anonyme";
    public $age = 0;

    public function sePresenter() {
      echo $this->nom . ", " . $this->age . " ans<br>";
    }
  }

  $p1 = new Personne();
  $p1->nom = "Amina";
  $p1->age = 22;
  $p1->sePresenter();

  $p2 = new Personne();
  $p2->nom = "Yassine";
  $p2->age = 30;
  $p2->sePresenter();
?>
RENDU

Amina, 22 ans
Yassine, 30 ans

📝
Le dollar de $this

On écrit $this->nom sans second $ devant la propriété : pas $this->$nom (ce qui serait une propriété variable). La flèche -> se lit « l'attribut / la méthode de l'objet courant » : $this->nom ⇔ « le nom de cet objet-ci ».

⚡ EXO FLASH La ville qui suit l'objet

  2. Créez deux objets, donnez à $p1 seule une ville différente, appelez habite() sur chacun.
  3. Prévoyez ce qu'affiche un troisième objet $p3 = new Personne(); qu'on ne touche pas, puis vérifiez : chaque objet porte ses propres valeurs, le défaut de la classe pour le reste.
Voir un début de correction

    public $nom = "Anonyme";
    public $ville = "Inconnue";
    public function habite() {
      echo $this->nom . " vit à " . $this->ville . "<br>";
    }
  }
  $p = new Personne();
  $p->ville = "Oran";
  $p->habite();   // "Anonyme vit à Oran"
?>
03

Le constructeur & getters/setters

La méthode __construct() est appelée automatiquement au moment du new. Elle sert à initialiser l'objet dès sa naissance. Quand une propriété devient private, l'extérieur y accède via un getter (getNom()) et la modifie via un setter (setAge()) qui peut appliquer des contrôles.

PHP — __construct & accessors 
<?php
  class Personne {
    private $nom;
    private $age;

    public function __construct(string $nom, int $age) {
      $this->nom = $nom;
      $this->setAge($age);
    }

    public function getNom(): string { return $this->nom; }

    public function setAge(int $age): void {
      if ($age >= 0) $this->age = $age;
    }

    public function getAge(): int { return $this->age; }
  }

  $p = new Personne("Sara", 25);
  echo $p->getNom() . " a " . $p->getAge() . " ans";
  $p->setAge(-5);          // refusé : l'ancienne valeur
  echo " / " . $p->getAge();
?>
RENDU

Sara a 25 ans / 25

💡
Pourquoi masquer les propriétés ?

Un setter est un guichet de contrôle : date de naissance impossible, âge négatif, e-mail invalide… tout est vérifié à un seul endroit au lieu d'être recopié dans tout le reste du programme.

04

La visibilité : public, private, protected

La visibilité contrôle qui peut lire ou modifier un membre d'une classe. C'est le fondement de l'encapsulation : par défaut, on masque tout ce qui n'a pas besoin d'être vu de l'extérieur.

VisibilitéDans la classeDans une sous-classeDepuis l'extérieur
publicOuiOuiOui
protectedOuiOuiNon
privateOuiNonNon
⚠️
Tout en public ? Une bombe à retardement

Si n'importe quel code peut écrire $compte->solde = -99999;, aucune donnée n'est plus fiable. Déclarez private par défaut et exposez des méthodes utiles : l'objet garantit lui-même sa cohérence via ses setters et getters.

Écrivez toujours la visibilité explicitement devant chaque membre : une méthode déclarée sans mot-clé devient public sans prévenir — un trou d'encapsulation involontaire — et var $nom; est l'ancienne écriture d'une propriété publique, à laisser aux tutoriels des années 2000. Notez aussi que private est défini par classe et non par objet : dans une méthode de Personne, deux objets Personne peuvent lire mutuellement leurs propriétés privées — c'est ce qui permet d'écrire proprement une méthode de comparaison entre deux instances.

05

static, self & interfaces

Un membre static appartient à la classe elle-même, pas à un objet : on l'appelle Classe::methode() sans faire de new, et il ne connaît pas $this. Réservez-le au transverse : compteurs, configuration, utilitaires. À l'intérieur, on référence la classe avec self::. Une interface définit quant à elle un contrat de méthodes publiques qu'une classe s'engage à implémenter avec implements.

PHP — static, self & interface 
<?php
  interface Forme {
    public function aire(): float;
  }

  class Cercle implements Forme {
    const PI = 3.14159;
    private static $nb = 0;

    public function __construct(private float $r) {
      self::$nb++;
    }

    public function aire(): float {
      return self::PI * $this->r * $this->r;
    }

    public static function combien(): int {
      return self::$nb;
    }
  }

  $c1 = new Cercle(1.0);
  $c2 = new Cercle(2.0);
  echo round($c1->aire(), 2) . " / " . Cercle::combien();
?>
RENDU

3.14 / 2

06

Héritage : extends et parent::

Le mot-clé extends fait hériter d'une classe enfant toutes les propriétés et méthodes publiques ou protected de son parent. L'enfant peut redéfinir (override) une méthode, et revenir à celle du parent avec parent::. Un protected reste accessible à l'enfant sans être public.

PHP — extends & parent:: 
<?php
  class Personne {
    protected $nom;

    public function __construct(string $nom) {
      $this->nom = $nom;
    }

    public function sePresenter(): void {
      echo "Je suis " . $this->nom;
    }
  }

  class Etudiant extends Personne {
    private $filiere;

    public function __construct(string $nom, string $filiere) {
      parent::__construct($nom);
      $this->filiere = $filiere;
    }

    public function sePresenter(): void {
      parent::sePresenter();
      echo ", étudiant en " . $this->filiere;
    }
  }

  $e = new Etudiant("Nadia", "GTR");
  $e->sePresenter();
?>
RENDU

Je suis Nadia, étudiant en GTR

💡
Héritage : " EST-UN "

Utilisez extends seulement quand la relation « un Etudiant est une Personne » est vraie (héritage « EST-UN »). Ce qui « se possède » (une voiture a un moteur) se modélise par une propriété, pas par un extends — cela évite les hiérarchies artificielles et profondes.

⚡ EXO FLASH Enseignant hérite de Personne
  1. Dans flash_heritage.php, déclarez Enseignant extends Personne (la classe du début de section) sans redéclarer de constructeur, puis créez new Enseignant("Alice") : pourquoi est-ce que ça marche ?
  2. Redéfinissez sePresenter() : appelez parent::sePresenter() puis complétez avec « , prof de GTR ».
  3. Prévoyez le résultat de $e->nom = "Bob"; écrit à l'extérieur de la classe, puis vérifiez : $nom est protected, l'héritage ne rend pas la propriété publique pour autant.
Voir un début de correction 
<?php
  class Enseignant extends Personne {
    public function sePresenter(): void {
      parent::sePresenter();
      echo ", prof de GTR";
    }
  }
  $e = new Enseignant("Alice");
  $e->sePresenter();  // "Je suis Alice, prof de GTR"
?>
07

Exercices pratiques

EX 01 🎂 Premier objet : classe Personne
  1. Créez exo_personne.php avec une classe Personne : propriétés $nom et $age.
  2. Ajoutez une méthode sePresenter() qui affiche « Je suis nom, j'ai age ans ».
  3. Instanciez deux objets avec des valeurs différentes, et appelez la méthode sur chacun.

Indice : un objet par variable ($p1, $p2) — chaque $this désigne l'objet appelant.

EX 02 🔐 Compte bancaire encapsulé
  1. Créez une classe Compte : propriété private $solde, constructeur avec un solde de départ.
  2. Ajoutez deposer($m) refusant un montant négatif, et retrait($m) refusant de passer en négatif.
  3. Ajoutez le getter getSolde(), puis testez : déposez 100, retirez 30, essayez de retirer 2000.

Indice : les vérifications se font dans les méthodes, jamais à l'extérieur — c'est tout l'intérêt de private.

EX 03 📐 Interface Forme & implémentations
  1. Déclarez une interface Forme avec une méthode aire(): float.
  2. Implémentez deux classes Carre (côté) et Cercle (rayon) qui respectent ce contrat.
  3. Ajoutez dans Cercle une constante de classe const PI = 3.14159; utilisée par aire().

Indice : dans une classe, la constante se référence avec self::PI, pas $this->PI.

EX 04 🎓 Famille Etudiant extends Personne
  1. Partez de la classe Personne (nom protégé, constructeur, sePresenter()).
  2. Créez Etudiant extends Personne avec une $filiere privée et son constructeur appelant parent::__construct($nom).
  3. Surchargez sePresenter() : réutilisez parent::sePresenter() puis ajoutez « étudiant en filiere ».

Indice : la propriété $nom doit être protected (et non private) pour être utilisée par Etudiant.

08

Bilan & mini-glossaire

Ce que vous maîtrisez

  • Distinguer la classe (plan) de l'objet (instance créée avec new)
  • Déclarer des propriétés et des méthodes, et utiliser $this
  • Initialiser un objet avec __construct()
  • Protéger les données avec private + getters / setters
  • Choisir entre public, protected et private
  • Utiliser static, self:: et les constantes de classe
  • Définir un contrat avec une interface et l'appliquer via implements
  • Hériter avec extends, réutiliser le parent avec parent::
🚨
Erreurs fréquentes
  • Oublier new et appeler la classe comme une fonction → erreur fatale.
  • Écrire $this->$nom (deux $) au lieu de $this->nom.
  • Accéder de l'extérieur à une propriété private → Cannot access private property.
  • Appeler une propriété au lieu de sa méthode : $obj->getAge sans () → null / erreur.
  • Hériter « parce que ça existe » : gardez extends pour de vraies relations « EST-UN ».

Mini-glossaire

Classe
Plan structuré décrivant propriétés et méthodes d'un type d'objets.
Objet
Instance d'une classe, créée avec new, avec ses propres valeurs.
$this
Référence à l'objet courant, utilisée dans les méthodes.
__construct
Méthode exécutée automatiquement à la création de l'objet.
Getter / Setter
Méthodes publiques de lecture / modification contrôlée d'une propriété privée.
Visibilité
Niveau d'accès d'un membre : public, protected ou private.
static
Membre qui appartient à la classe, appelé via Classe:: sans instance.
Héritage
Mécanisme extends : une classe enfant récupère et enrichit le parent.
